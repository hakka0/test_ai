# 샬레 오토 배틀

`bachess.zip`을 바탕으로 PC판 상점, 대기석, 유닛 상세, 편성 미리보기와 전장에 구 버전의 유닛 이미지를 연결한 프로젝트입니다. 사용자 1명과 봇 7명이 브라우저에서 대전합니다.

## 실행

이 폴더에서 아래 명령을 실행한 뒤 [http://localhost:3000/](http://localhost:3000/)을 엽니다. Python은 정적 파일을 제공하는 데 사용합니다.

```sh
python -m http.server 3000 --directory public
```

## 유닛 이미지

구 버전의 초상화 20장과 6방향 전장 스프라이트 시트 20장을 `public/units/blue-archive/`에 복사했습니다. 아리스는 ZIP에서 `alice`, 이미지 파일에서 `aris`라는 이름을 사용합니다.

동일한 학생이 있는 13종은 그대로 연결했습니다. 구 버전에만 있던 7종은 ZIP에서 역할과 무기 유형이 가까운 유닛에 배정하고 화면에 표시되는 이름을 맞췄습니다.

| ZIP의 표시 이름 | 새 표시 이름과 이미지 |
| --- | --- |
| 세리카 | 이즈나 |
| 하나코 | 나츠 |
| 모모이 | 마키 |
| 무츠키 | 네루 |
| 카요코 | 하루나 |
| 하스미 | 와카모 |
| 마리 | 히후미 |

아야네, 하루카, 노노미, 나기사는 ZIP의 기본 일러스트를 사용합니다. 모든 유닛의 코스트, 역할, 소속, 능력치, 스킬은 ZIP의 규칙을 따릅니다.
