# 샬레 오토 배틀

`bachess.zip`을 바탕으로 PC판 상점, 대기석, 유닛 상세, 편성 미리보기와 전장에 구 버전의 유닛 이미지를 연결한 프로젝트입니다. 사용자 1명과 봇 7명이 브라우저에서 대전합니다.

## 실행

이 폴더에서 아래 명령을 실행한 뒤 [http://localhost:3000/](http://localhost:3000/)을 엽니다. Python은 정적 파일을 제공하는 데 사용합니다.

```sh
python -m http.server 3000 --directory public
```

## PC판 상점과 전장

- 아군과 상대 진영은 각각 8열×4행입니다. 내 유닛은 중앙선 아래쪽 32칸에 배치합니다.
- 전장 뒤쪽은 더 좁게 보이는 원근을 적용합니다. PC 전장의 일반 유닛은 칸 가로 폭 80%로 표시하며 발과 그림자를 칸 중앙에 맞춥니다. 준비 단계에 그림이 겹치면 포인터가 가리키는 배치 칸의 학생을 먼저 선택합니다.
- PC에서 준비 중인 유닛은 화면 아래쪽을 봅니다. 전투가 시작되면 상대 진영을 향하고, 전투 중에는 현재 표적을 바라봅니다.
- PC 전투는 기본 속도로 진행합니다. 20초를 넘으면 피버타임에 들어가 양쪽의 기본 공격·스킬 피해는 1.5배, 회복·배리어는 0.5배가 됩니다.
- 상점 잠금은 현재 상품을 다음 라운드에 한 번 넘깁니다. 다음 준비 단계가 시작되면 잠금이 자동으로 풀리며, 이미 구매한 칸도 그 라운드까지 그대로 비어 있습니다.
- 도트 유닛의 조준 방향에 따라 총기 6종이 전장에 표시됩니다. 화면 아래쪽을 볼 때 총이 유닛 앞에, 위쪽을 볼 때 뒤에 놓입니다. 총기 PNG는 `public/units/weapons/`에 있습니다.

## 유닛 이미지

구 버전의 초상화 20장과 6방향 전장 스프라이트 시트 20장을 `public/units/blue-archive/`에 복사했습니다. 아리스는 ZIP에서 `alice`, 이미지 파일에서 `aris`라는 이름을 사용합니다.

동일한 학생이 있는 13종은 그대로 연결했습니다. 구 버전에만 있던 7종은 ZIP에서 역할과 무기 유형이 가까운 유닛에 배정하고 화면에 표시되는 이름을 맞췄습니다.

| ZIP의 표시 이름 | 새 표시 이름과 이미지 |
| --- | --- |
| 세리카 | 이즈나 |
| 하나코 | 나츠 |
| 모모이 | 마키 |
| 무츠키 | 네루 |
| 카요코 | 하루나 |
| 하스미 | 와카모 |
| 마리 | 히후미 |

아야네, 하루카, 노노미, 나기사는 ZIP의 기본 일러스트를 사용합니다. 모든 유닛의 코스트, 역할, 소속, 능력치, 스킬은 ZIP의 규칙을 따릅니다.

## 지정 툰 ZIP 적용 — 2026-11-23

PC판의 이미지 20종은 `toon-pixel-test-20261117.zip`의 툰 버전을 사용합니다. `public/units/toon-pixel-test-20261117/`에 시트·아이콘과 출처 기록을 보관합니다. 시트의 원본 프레임은 256×256px입니다. 6방향을 원본 크기에 맞춰 잘라 부드럽게 축소합니다. 20종의 이름·능력치·역할·스킬·소속 매핑과 8인 PVP 흐름은 유지합니다.

검사: `node bachess/tools/check-toon-zip.mjs`(저장소 루트에서 실행). PNG 42개의 해시·규격과 실제 유닛 20종의 초상화 경로·방향별 프레임 120개, PC 표시 크기를 검사합니다. 미니언 2종도 아카이브에 포함하며 현재 PVP의 구성은 바꾸지 않습니다.
