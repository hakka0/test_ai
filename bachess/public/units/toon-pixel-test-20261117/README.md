# toon-pixel-test-20261117.zip 게임용 이미지

지정 ZIP의 툰 원본에서 준비한 캐릭터 20종의 시트·아이콘과 미니언 2종입니다. 시트는 768×512, 6방향의 원본 프레임은 256×256이며 정면 아이콘도 256×256입니다. ZIP의 512px 프레임을 252px로 축소하고 사방 2px의 투명 여백을 둡니다.

PC판은 이 원본 프레임을 읽어 기존과 같은 128 CSS 픽셀 크기로 표시합니다. `archive-source.json`은 ZIP SHA-256·원본 경로·게임용 PNG의 해시를 기록합니다. PVP에서 사용하는 20종의 이름과 매핑은 기존 `data.js`를 따릅니다. 코드로 그리는 4종과 PVE의 구현 범위는 유지합니다.
