# 게임용 툰 일러스트

`public/units/toon-pixel-test`의 원본 생성 이미지를 게임 표시용으로 준비한 리소스입니다. 캐릭터 20종의 시트·아이콘과 미니언 2종을 포함합니다.

- 시트 768×512px, 3열×2행, 프레임 256×256px.
- 원본의 각 512px 프레임을 따로 Lanczos3 방식으로 252px에 축소하고 사방 2px의 투명 여백을 두었습니다. 인접 프레임의 색이 섞이지 않으며 헤일로·무기가 프레임 경계에 닿지 않습니다.
- 아이콘은 준비된 시트의 정면 프레임(인덱스 1)과 동일한 픽셀입니다. PNG는 손실 없이 압축했습니다.
- 전장에서는 부드러운 축소와 기존의 불투명 영역 기반 발 정렬을 사용합니다. 고해상도 생성 원본은 별도 디렉터리에 보존합니다.
- 게임은 기본으로 이 세트를 사용합니다. URL에 `?art=pixel`을 붙이면 기존 128px 도트 시트와 최근접 보간을 사용합니다. 유닛 종류·능력치·경기 규칙은 같습니다.

`manifest.json`에 원본/시트 SHA-256과 준비 규격을 기록했습니다.
