# 도트 질감을 섞은 툰 일러스트 — 테스트 세트

원본 저장소 `hakka0/test_ai`, 기준 커밋 `9f24e5f81f2c957a659b0644228e1c18cb6e9bc8`의 모든 이미지 유닛을 대상으로 만들었습니다. 캐릭터 20종과 미니언 2종을 포함합니다.

매끈한 외곽선, 큰 셀 명암 면, 부분적인 사각 하이라이트를 사용했습니다. 머리색·헤일로·무기·복장 등 원본의 구분 특징을 참고해 새로 그린 스타일 검토용 이미지입니다. 생성된 세부 장식과 시점은 원본과 차이가 있을 수 있으며, 게임 적용 전 검토 대상입니다.

## 파일

- `blue-archive/*.png`: 캐릭터별 3열×2행 시트 20장. 각 시트는 1536×1024px, 프레임은 512×512px입니다.
- `blue-archive/icons/*.png`: 각 시트의 정면 프레임에서 픽셀 변경 없이 추출한 아이콘 20장. 512×512px입니다.
- `minions/*.png`: 드론과 센트리 각 1장. 원본 생성 해상도 1254×1254px를 유지합니다.
- `comparison-light.png`, `comparison-dark.png`: 22종 전체의 정면을 48·64·80px로 비교한 별도 합성 검토표입니다. 전장 배경은 비교용이며 실제 게임 캡처가 아닙니다.
- `directions-review.png`: 캐릭터 20종의 6방향 전체를 모은 검토표입니다.
- `manifest.json`: 원본 커밋, 생성 방향, 프롬프트, 파일 규격, 프레임 경계, SHA-256을 기록했습니다.
- `validation.json`: 리소스 검증 범위와 웹 미리보기 검증 한계를 기록했습니다.

6방향 순서는 기존과 같습니다.

| 인덱스 | 방향 | 위치 |
| --- | --- | --- |
| 0 | 정면 왼쪽 | 위 왼쪽 |
| 1 | 정면 | 위 중앙 |
| 2 | 정면 오른쪽 | 위 오른쪽 |
| 3 | 후면 왼쪽 | 아래 왼쪽 |
| 4 | 후면 | 아래 중앙 |

## 비교 화면

프로젝트의 `public/unit-art-test.html`을 열거나, 기존 개발 서버에서 `/unit-art-test.html`에 접속합니다. Pages의 하위 경로에서도 상대 경로로 리소스를 찾습니다.

관리형 Cloud 환경에서는 `bash scripts/preview-unit-art.sh`로 실행합니다. 웹 서버를 전용 루프백 네트워크에 두고 공식 `sites-preview` 중계로 연결해 같은 `4173` 포트의 충돌을 피합니다. 명령 실행에 필요한 권한은 환경의 승인된 실행 경로를 사용합니다. 이미 미리보기가 있으면 상태를 표시하며, 다른 미리보기로 전환할 때는 먼저 `sites-preview stop`을 실행합니다.

압축 묶음에서는 전체 폴더를 풀고 `unit-art-test.html`을 열면 됩니다. 원본 비교 이미지도 함께 들어 있으며 외부 서비스나 로그인은 사용하지 않습니다.

정면·후면을 포함한 6방향 선택, 밝은 전장·어두운 전장·투명 확인 배경, 이름 검색, 개별 PNG 다운로드, 전체 시트 보기를 제공합니다. 같은 슬롯 크기에서 원본은 최근접 보간, 새 이미지는 부드러운 축소로 비교합니다.

## 게임 적용 범위

현재 게임의 이미지 경로, 128px 프레임 규격, Phaser 텍스처 필터는 수정하지 않았습니다. 이 세트는 별도 테스트 리소스입니다.

향후 게임에 적용할 때는 이 세트에 한해 512px 프레임과 부드러운 축소를 사용하고, 기존의 불투명 영역 측정 및 발 정렬 로직을 적용해야 합니다. 기존 128px 시트 자리에 경로만 교체하면 프레임이 잘못 나뉩니다. 아이콘 역시 `image-rendering: auto`로 확인해야 합니다.

## 검증

22종의 ID 전체 포함, 122개 프레임의 유효한 그림·투명 배경, 캐릭터의 3×2 구조, 아이콘과 정면 프레임의 픽셀 일치, 원본 파일 보존을 검사합니다. 축소 검토표는 새 그림을 다시 생성하거나 리터칭하지 않고 원본/신규 리소스를 각각 지정된 보간으로 축소해 합성합니다.

미리보기 복구 후 프로젝트의 Chromium 검사 도구로 비교 페이지의 22종 로딩·검색·방향·배경 전환·새로고침, PC·모바일·회전의 9개 크기를 확인했습니다. 실제 게임 화면·실기기 검증과 게임 규칙·네트워크 검사는 포함하지 않습니다. 공유 브라우저 자동 제어용 MCP 연결은 현재 별도 오류가 남아 있으며, 이 검증은 프로젝트 Chromium 실행 결과입니다.
