# 0.13.2 모바일 조작

## 화면 모드 선택

기본 모드는 User-Agent로 정하며 창 크기/회전은 모드를 바꾸지 않습니다. 게임 화면 맨 아래 PC/모바일 버튼으로 직접 선택하고 저장합니다. 자동 판별로 복원하면 기본 판별로 돌아갑니다. 모바일 고정 조작 바와 짧은 가로 화면의 축소 규칙은 모바일 모드에만 적용합니다. PC/모바일 안에서는 실제 폭에 맞게 배치를 조정합니다. 자세한 사용과 확인은 `SCREEN_MODE.md`를 보세요.

## 실행과 기본 흐름

`npm ci` → `npm run build` → `npm start`, 또는 개발은 `npm run dev`로 실행합니다. Windows PowerShell은 `npm.cmd`를 사용하세요. 최신 ZIP의 클라이언트와 서버를 함께 사용해야 합니다. 같은 Wi-Fi의 휴대폰에서는 PC의 LAN 주소로 접속합니다. 실제 VPS 배포는 별도 작업입니다.

| 조작 | 동작 |
|---|---|
| 내 유닛 한 번 터치 / 키보드 Enter | 선택. 팝업을 자동으로 열지 않음 |
| 선택 후 빈 아군 칸 터치 | 배치. 출전 정원·점유 칸을 검사 |
| 선택 후 빈 대기석 터치 | 지정 슬롯으로 이동 |
| 유닛을 드래그 후 드롭 | 빈자리는 이동, 다른 내 유닛 위는 서로 자리 교환. 허용 칸 강조와 반투명 이미지 |
| 상세 | 선택 유닛 능력치·스킬·장착 장비 표시 |
| 장비 | 상세 창의 장비 관리를 펼침. 준비 중 장착·해제·이동 |
| 대기석 | 전장 선택 유닛을 첫 빈 대기석으로 회수 |
| 해제 / 창 밖에서 Escape | 선택 해제 |
| 판매 → 판매 확인 | 대상·강화 등급·금액을 확인한 뒤 판매 |
| 판매 취소 / 창 닫기 / Escape | 판매 확인 취소. 창을 닫아도 선택은 유지 |
| 상점 보기 / 대기석 보기 | 화면 전환. 리롤이나 결제를 하지 않음 |
| 준비 완료 | 서버 확인 뒤 잠금. 혼자 연습에서는 바로 전투 시작 |

대기석과 전장 유닛 위에서는 드래그를 우선합니다. 페이지 스크롤은 주변 패널/여백에서 할 수 있습니다. 전투 중에는 선택·상세 조회와 상점 리롤·구매가 가능합니다. 배치·판매·장비 변경은 준비 완료 전 준비 단계에서만 가능합니다. 전투 중 구매로 자동 합성돼도 현재 전투는 시작 당시 상태로 진행됩니다. 단순 선택은 전투 중에도 유지됩니다.

## 전투 기록 (0.10.0)

상단 중앙의 전투 기록 버튼을 누르면 진행표가 열립니다. 완료한 라운드를 누르면 상대/승패/양쪽 체력 감소/생존 유닛을 확인합니다. 상세만 닫거나 진행표 전체를 닫을 수 있으며 결과가 생겨도 자동으로 열리지 않습니다. 닫아도 현재 경기의 기록은 서버에 쌓입니다. 마지막 조회 상태와 재접속 처리는 BATTLE_HISTORY.md를 참고하세요.

## 라운드 보상 팝업 (0.13.1)

보상 선택 후보는 전장 위 팝업으로 표시합니다. 오른쪽 아래 눈 버튼을 누르는 동안 투명해지고 놓으면 복원됩니다. 닫기/Escape 후 상단 라운드 보상 보기로 다시 엽니다. 미선택 준비 완료/마감 시 자동 골드 규칙은 유지합니다. 기본 화면 구성은 0.12.0을 사용하며 상세 조작/검증은 `REWARD_POPUP.md`를 보세요.

## 자리 교환 (0.9.2)

다른 내 유닛이 있는 전장 칸이나 대기석 슬롯에 드롭하면 두 유닛의 위치를 교환합니다. 전장↔대기석, 전장↔전장, 대기석↔대기석을 지원하며 출전 정원·대기석이 꽉 차 있어도 가능합니다. 드롭 표시가 ‘자리 교환’으로 바뀝니다. 같은 위치에 놓으면 변경하지 않습니다. 유닛 ID·강화·장비는 그대로 유지합니다.

한 번 터치로 다른 유닛을 선택하는 동작은 유지합니다. 교환은 드래그로 실행하세요. 준비 완료 후·준비 마감·전투 중에는 교환할 수 없습니다. 빈 전장 칸으로 이동해 출전 수가 늘어나는 경우는 기존 정원 제한을 적용합니다. 대기석 버튼으로 자동 회수할 때는 기존처럼 빈 슬롯이 필요합니다.

## 입력 처리

한 요청이 처리 중이면 다른 변경 요청은 잠시 비활성화합니다. 동일 스냅샷이 반복되어도 대기 상태를 해제하지 않습니다. 서버 상태 변경·거부 응답·단계 변경·연결 해제로 해제하며, 재접속 후 새 스냅샷 전까지는 입력을 잠급니다. 선택과 정보 조회는 가능합니다.

드래그 뒤 발생하는 후속 클릭만 무시합니다. 새로운 터치와 키보드 입력은 이 차단에 포함하지 않습니다. 단순 터치에서 작은 움직임은 허용하되 8px 이상 이동하면 드래그로 처리합니다. 유효한 칸에 드롭해야 이동하며 같은 위치에는 중복 요청을 보내지 않습니다.

회전, 창 크기 변경, 화면 숨김·포커스 이탈, 추가 손가락, pointercancel, 포인터 캡처 상실, 준비 마감은 드래그를 취소합니다. 합성·디버깅 프리셋/복원으로 선택 대상이 변하면 기존 드래그를 버립니다. 판매 확인은 선택한 ID·강화 등급·가격과 연결되어 다른 대상에 재사용할 수 없습니다.

## 화면 구성

폰 세로는 하단 조작 바를 고정하며 안전 영역과 콘텐츠 하단 여백을 확보합니다. 전장·대기석에서 선택한 유닛을 상세 패널까지 스크롤하지 않고 확인할 수 있습니다. 상세 창에는 장비 관리와 닫기·판매 버튼을 함께 제공합니다. 오류 메시지는 상세 창 안에서도 표시합니다.

작은 가로 화면은 한 열로 배치하고 620px 이상 가로 화면부터 두 열을 사용합니다. 페이지는 세로로 스크롤합니다. 상점의 녹색 배경과 상점/대기석 표시는 유지합니다.

## 실행 검증 상태

규칙·입력 테스트 77개와 서버 통신 3개, TypeScript/Vite 빌드가 통과했습니다. 입력 테스트는 실제 규칙 엔진에 배치/판매 명령을 적용하여 좌표·정원·장비 반환도 확인합니다.

브라우저 자동 검사는 실행을 시도했지만 Chromium 실행 파일이 없어 화면을 열기 전에 실패했습니다. 터치 이벤트·레이아웃·모달의 실제 브라우저 동작과 실기기 조작감을 검증한 결과는 아닙니다. 다음 명령으로 실행할 수 있습니다(Playwright는 게임 실행용 의존성이 아닙니다).

```powershell
npm.cmd install --no-save --package-lock=false playwright
npx.cmd playwright install chromium
npm.cmd run build
npm.cmd run test:browser
```

검사는 임시 개발 서버 2588을 사용합니다. 지정한 Chromium이 있으면 CHROME_PATH 환경 변수로 경로를 넣을 수 있습니다.

## 화면 확인 목록

- 390×844, 320×740 세로 / 480×320, 844×390 가로 / PC에서 가로 넘침과 하단 조작 바 겹침 확인.
- 유닛을 선택하고 즉시 빈 칸/대기석을 터치했을 때 팝업 없이 이동 확인.
- 드래그 취소·잘못된 칸·회전 중 드롭에서 유닛이 이동하지 않는지 확인.
- 상세 닫기·장비 버튼·판매 취소/확인, 강화 유닛 가격과 장비 반환 확인.
- 재접속·상점/대기석 전환·준비 완료·전투 중 리롤·구매 가능과 배치·판매·장비 잠금와 키보드 Enter/Escape 확인.
- 느린 네트워크에서 처리 중 반복 결제가 없는지, 거부 응답 뒤 다시 조작할 수 있는지 확인.

이는 아직 남은 화면/실기기 확인 목록이며 통과한 항목 목록이 아닙니다. 밸런스 조정은 이번 작업에서 하지 않았습니다.
