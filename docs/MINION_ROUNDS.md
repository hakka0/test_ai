# 미니언 도입부·연속 골드 (v0.20.53)

실제 서버의 PvP 방은 처음 **3번의 전투**에서 각 플레이어가 자기 전장의 미니언과 싸웁니다. 두 플레이어의 전투는 좌표가 같아도 서로 공격·스킬·이동에 영향을 주지 않습니다. 둘 다 전투를 마치면 결과로 넘어갑니다. 4번째 전투부터 기존 5초 매칭과 유저 간 대전을 진행합니다. 일반 혼자 연습은 기존 봇 대전을 유지합니다.

현재 스테이지 번호의 5라운드 묶음은 유지합니다. 따라서 표시상 2-1·2-2·2-3이 미니언전이며 첫 유저 대전은 2-4입니다. 첫 3개의 큰 스테이지(15라운드)를 뜻하지 않습니다.

| 전투 | 미니언 수/개인 전장 | 모두 처치했을 때 개인 보상 |
| --- | --- | --- |
| 1 | 1기 | 1~2등급 유닛 1명 + 2G |
| 2 | 2기 | 강철 조각 1개 + 2G |
| 3 | 3기 | 새벽의 검 1개 + 1~2등급 유닛 1명 + 3G |

보상은 승리 일괄 지급이 아니라 **각 미니언 처치 순간** 지급합니다. 부분 처치 후 실패해도 이미 받은 보상은 유지하며 미처치 미니언은 보상을 주지 않습니다. 드롭 아이콘과 획득 이름/수량을 표시하고 자동 수령합니다. 클릭할 보상 상자나 추가 팝업은 없습니다. 효과 줄이기에서는 이동 없이 아이콘/이름으로 알립니다.

유닛은 공유 풀을 사용하며 본인 3성 완성 종류를 제외합니다. 전투 도중 획득하므로 빈 대기석에 넣고 다음 준비에서 합성합니다. 만석이면 해당 유닛의 레어도 가격만큼 골드로, 받을 수 있는 종류가 없으면 2G로 바꾸어 실제 지급한 보상 종류로 표시합니다. 장비/재료는 보관함으로 보냅니다. 미니언은 상점·공유 풀·순위표에 포함하지 않습니다.

도입부에서는 플레이어 체력·승수·연승/연패를 바꾸지 않습니다. 기본 준비 수입·이자·경험치와 다음 준비의 상점 갱신은 유지합니다. 미니언 상세는 전장 유닛처럼 확인할 수 있으며 중립 유닛은 판매/장착할 수 없습니다. v0.20.55에서 전장 좌우 카드를 제거했으며 남은 미니언은 전장과 유닛 상세에서 확인합니다. 기록은 본인 미니언전의 승패·피해 기여도를 보여주며 다른 유저의 미니언전 기록과 섞지 않습니다.

## 연승·연패 보너스

| 연속 횟수 | 전투 종료 직후 추가 골드 |
| --- | --- |
| 0~1회 | 0G |
| 2~3회 | 1G |
| 4회 | 2G |
| 5회 이상 | 3G |

연승과 연패에 같은 기준을 적용합니다. 결과를 반영한 현재 연속 횟수로 계산합니다. 승리 1G는 별도로 유지합니다. 무승부는 연속을 초기화하며, 방향이 바뀌면 1회부터 다시 셉니다. 기본 5G와 전투 시작 잔액 기준 이자는 다음 준비에 지급하며 연속 보너스를 다시 더하지 않습니다. 최대 라운드/탈락 직전 전투에도 종료 시 보너스를 지급합니다.

## 직접 조절할 위치

- `shared/match-rules.ts`: `streakGold()`의 횟수/금액.
- `shared/engine.ts`: `finish()`의 지급 시점과 `resolveMinions()`의 처치별 보상. 유닛 보상 범위는 레어도 1~2입니다.
- `shared/minions.ts`: 첫 3전투 상수, 미니언 생성/체력·공격·방어력/모습. 초기 체력은 85/100/115, 공격력은 4/5/6, 방어력 8, 공격 주기 1.5초입니다. 보병 사거리 1, 드론 사거리 3입니다.
- `server/GameRoom.ts`: 실제 PvP 방에서 `newMatch('duel', INTRO_MINION_ROUNDS)`로 도입부를 활성화합니다. `newMatch()`의 두 번째 인수는 시뮬레이션·검사에서 도입부를 포함할지 정하는 경기 설정이며 클라이언트 요청으로 바꿀 수 없습니다.
- `public/units/minion-sentry.svg`, `minion-drone.svg`: 배경이 투명한 500×500 미니언 이미지.
- `client/combat-effects.ts`: `loot` 이벤트의 코인/유닛/장비 아이콘·이름·낙하/사라짐 연출. 지급은 서버가 수행하므로 이 연출을 수정해도 획득량은 변하지 않습니다.
- `shared/snapshot.ts`, `client/scouting.ts`: 실제 유저와 중립 상대를 구분하고 각 전장의 두 진영만 표시합니다.

개발 서버에서는 혼자 연습 → 개발 도구 → **미니언전 시작** 프리셋으로 같은 전투/보상 규칙을 확인할 수 있습니다. 개발 연습용 프리셋은 실제 2인 PvP 입장 검사를 대신하지 않습니다. 배속·정지·단계 진행·저장 복원을 사용할 수 있으며 운영 서버에서는 개발 기능이 노출되지 않습니다.

실제 서버는 현재 2인이며 6인 유저 대전은 후속 작업입니다. [검증 기록](VALIDATION.md), [메인 화면 안내](MAIN_INTERFACE.md).
