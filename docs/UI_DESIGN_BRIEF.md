# 외부 UI 디자인 도구에 전달할 상세 요청서

기준: autochess-web v0.20.67 / 2026-11-02.
용도: Stitch·Figma Make 등에서 메인 게임 화면의 디자인 후보를 비교하기 위한 요청서. 이 문서 작성으로 게임 UI나 규칙을 변경하지 않습니다.
현재 일반 사람 대전은 2명, PvP 연습은 실제 사용자 1명+서버 봇 5명입니다. 아래의 최대 6인 구성은 디자인 목표이며 실제 사람 6인 입장을 구현했다는 뜻이 아닙니다.

아래 요청문과 현재 게임 스크린샷을 함께 전달하세요. PC 전체 화면, 유닛 상세가 열린 화면, 상점 드래그 화면, 모바일 가로 전체 화면을 참고 자료로 사용합니다. 기존 그림은 임시 에셋이며 FPS 캐릭터를 사용하는 방향에 맞춰 UI를 설계합니다.

---

FPS 캐릭터를 사용하는 오토체스 웹게임의 메인 플레이 화면을 재설계해 주세요. 아래에서 ‘현재 규칙/필수 유지’로 적은 내용은 보존하고, 패널 비율·간격·정보 묶음·시각적 계층은 개선해 주세요. 완성된 게임 엔진을 새로 만들기보다, 비교 가능한 화면과 핵심 조작의 UI 프로토타입이 필요합니다.

1. 게임의 정체성과 플레이 흐름

- 플레이어가 여러 캐릭터를 구매하고, 대기석에서 전장으로 배치하고, 장비와 출전 조합을 맞추면 전투가 자동으로 진행되는 전술 게임입니다.
- 플레이어의 조작은 구매·배치·장비·성장·관전에 집중하며 캐릭터의 이동·공격·스킬 사용은 자동입니다. 총기 이미지는 캐릭터/전투 효과/능력치 아이콘으로 표현합니다.
- 디자인 목표는 최대 6명이 매 전투 1:1로 매칭되는 형태입니다. 남은 플레이어 체력과 다른 유저의 편성을 확인하며 운영합니다.
- FPS 캐릭터와 총격을 중심으로 표현합니다. 총구 화염·탄도·탄피·피격 스파크를 떠올리는 간결한 전술 분위기가 어울립니다. 최종 캐릭터 그림/세계관은 제공 에셋과 추후 설정을 따릅니다.
- 전투 중에는 관전과 정보 조회를 하며, 준비 중에는 구매·리롤·경험치·배치·장비·조합을 빠르게 판단합니다.
- 첫 3번 전투는 미니언전이며 유닛·골드·장비 보상 연출이 있습니다. 이후 일반 PvP 전투를 진행합니다.
- 준비 → 5초 매칭 → 전투 → 결과 → 다음 준비의 상태를 구별합니다. 전투는 기본 20초 후 피버타임으로 전환될 수 있습니다.
- 화면의 목적은 전투를 보기 쉽게 유지하면서 구매·편성 판단을 빠르게 돕는 것입니다.

2. 제안하는 시각 방향

- 어두운 네이비/차콜 바탕, 적당히 둥근 사각 패널, 얇은 경계선, 선명한 수치/아이콘과 절제된 발광을 기본 방향으로 제안해 주세요.
- 유닛 초상화와 전장 안 캐릭터의 존재감을 높이고, 패널은 전투와 조작을 지원하도록 구성해 주세요.
- 밝은 강조는 선택 유닛·합성 가능한 상품·현재 조합 단계·중요 버튼 같은 의미 있는 상태에 사용합니다.
- 한국어 이름·설명·숫자가 좁은 화면에서도 읽히는 글자 크기와 줄바꿈을 사용합니다.
- 패널 수와 반복 문구를 줄이고, 같은 성격의 정보를 한 덩어리로 묶어 주세요.
- 게임의 공격/방어 속성, 소유 관계, 조합 단계 색을 구분할 수 있게 위치·아이콘·형태도 함께 사용해 주세요.

3. 전장과 대기석: 필수 유지

- 전체 전장은 8열×8행의 정사각형입니다. 상하 두 진영이 같은 판을 사용하며 각 진영은 4행입니다.
- 전장이 화면의 시각적 중심이며 넓고 명확해야 합니다. 패널·상점·순위표가 전장과 겹치지 않게 합니다.
- 준비 중에는 전체 전장 중앙에 ‘편성 수 / 편성 가능 수’를 표시합니다. 전투 중에는 숨깁니다.
- 선택한 유닛 머리 위에는 빛나는 노란 역삼각형, 해당 칸에는 노란 윤곽선을 표시합니다.
- 대기석은 12칸이며 빈칸과 유닛이 있는 칸 모두 정사각형입니다. 칸을 늘리거나 캐릭터를 가로/세로로 찌그러뜨리지 않습니다.
- 유닛 원본 이미지는 500×500px 정사각형입니다. 화면에서는 비율을 유지해 중앙에 표시합니다.
- 대기석과 전장은 캐릭터를 선택·드래그·배치·교환하기에 충분한 영역을 확보합니다.
- 플레이어의 큰 체력 표시를 전장 좌우에 반복하기보다 순위표의 체력을 주표시로 사용합니다.

4. 상점과 경제 조작: 현재 규칙 유지

- 상점 상품은 5개입니다. 카드에서 유닛 이미지·이름·가격·조합을 짧게 확인합니다.
- PC에서는 카드에 마우스를 올리면 ‘패시브 스킬 → 액티브 스킬’ 순서의 이름과 효과만 툴팁으로 봅니다.
- PC 클릭/모바일 한 번 터치로 바로 구매합니다. 별도 구매 확인 단계나 카드 하단 구매 버튼을 추가하지 않습니다.
- 카드를 내 대기석으로 드래그해 드롭해도 구매합니다. 원래 카드는 반투명, 복사본은 원본과 같은 크기로 포인터를 따라옵니다. 복사본 그림은 테두리 안을 정확히 채웁니다.
- 구매 가능한 내 대기석은 초록 강조, 대기석 밖 드롭과 취소는 구매하지 않는 상태로 구분합니다.
- 같은 종류 강화 1성이 2장 있어 다음 1장으로 합성할 수 있는 상품은 청백색 테두리와 은은한 발광으로 표시합니다.
- 골드 부족·대기석 가득 참·구매 불가 단계에서의 상태도 설계합니다. 준비 중 즉시 합성될 수 있는 상품의 예외는 기존 게임 규칙을 따릅니다.
- 전투/결과 중 구매한 유닛의 합성은 다음 준비 단계까지 보류합니다.
- 자동 상점 갱신은 다음 준비 시작에 발생합니다. 결과 단계에서 자동으로 새 상품을 보여주지 않습니다.
- 레벨/경험치 영역 전체는 경험치 구매 버튼입니다. 세로 경험치 게이지를 영역 왼쪽 가장자리에 붙입니다.
- 상점 왼쪽 운영 영역은 골드 공용 헤더 아래 경험치와 리롤 조작을 묶습니다. 리롤은 칸 전체를 누를 수 있습니다.
- 준비 완료도 칸 전체가 버튼입니다. 위쪽 연속 기록 헤더와 둥근 공용 외곽을 사용합니다.
- 연승은 불 아이콘/빨강 계열, 연패는 물 아이콘/파랑 계열입니다. 기록이 없으면 헤더 내용을 비웁니다.
- 연속 기록 자체를 호버/터치하면 ‘2~3회 +1G, 4회 +2G, 5회 이상 +3G’ 툴팁을 확인합니다.
- 내 유닛을 상점으로 끌어오면 상점 가운데 ‘판매’와 붉은 배경이 나타납니다. 구매 드래그와 판매 드래그의 대상/색을 명확히 구분합니다.
- 전투 중에는 대기석 유닛만 판매 가능하고 현재 싸우는 전장 유닛은 판매하지 못합니다.

5. 순위표와 관전: 필수 유지

- 순위표는 화면 오른쪽의 독립된 세로 열입니다. 6명 목록을 유닛 상세/전투 기록 패널 위에 쌓지 않습니다.
- 각 행은 순위·닉네임·남은 체력/체력바와 구분용 초상화 영역을 포함합니다. 낮은 화면에서는 목록 내부를 세로로 스크롤할 수 있습니다.
- 현재는 초상화 자리에 닉네임 이니셜을 사용합니다. 실제 프로필 사진은 향후 계획이므로 같은 자리에 넣을 수 있는 크기를 확보합니다.
- 내 유저, 현재 관전 중인 유저, 탈락한 유저를 서로 구별합니다. 경기 체력 변화는 전투 종료 직후 순위표에 반영합니다.
- 다른 유저를 선택하면 그 유저의 전장/대기석/조합과 전투 모습을 확인합니다. 내 시점으로 돌아오는 동작이 명확해야 합니다.
- 관전 중에도 경제 조작은 내 골드와 내 상점을 대상으로 합니다. 현재 표시하는 유저와 조작의 대상이 혼동되지 않아야 합니다.
- 준비/매칭에서도 다른 유저의 보유 편성은 조회하지만, 이번 전투에서 누구와 매칭됐는지는 전투 시작에 공개합니다.
- 매칭 중 경험치·리롤·준비 완료는 기존 허용 규칙을 따르고, 유닛 구매는 잠긴 상태를 보여줍니다.
- 상대 대기석에 상품을 드롭해 구매하는 동작은 거부합니다. 관전 중 내 상점의 클릭 구매는 가능합니다.

6. 출전 조합과 보유 장비

- 출전 조합은 메인 화면에서 즉시 확인합니다. 기본 위치는 보유 장비 위쪽입니다.
- 전장에 실제 배치한 유닛의 조합만 표시하고 0명인 모든 조합을 나열하지 않습니다.
- 각 행은 ‘현재 수 → 이름 → 2/4/6’의 압축 형식입니다. 예: ‘4 수호 2/4/6’.
- 같은 종류의 중복/다른 강화 등급/대기석은 인원 수를 늘리지 않습니다.
- 가장 높은 현재 단계 하나만 흰색입니다. 4명일 때 2/4/6 중 4만 흰색이며 나머지는 어두운 회색입니다.
- 비활성은 기본 어두운 색, 1단계 브론즈, 2단계 실버, 3단계 골드와 은은한 정적 발광입니다. 퍼플은 향후 4단계용이므로 현재 달성 단계로 표시하지 않습니다.
- 조합 행을 클릭/터치하면 효과 툴팁을 봅니다. 예: 제목 ‘수호 4’, 본문 ‘수호 유닛의 강화 기본 체력 15%/30%/50% 증가’. 현재 적용 수치 하나만 밝게 표시합니다.
- 조합 툴팁에 ‘조합’, ‘종’, ‘활성’, ‘몇 명 더 필요’나 긴 집계 안내를 반복하지 않습니다.
- 보유 장비는 아이콘 위주입니다. 아이템을 누르면 작은 상세 창에서 설명과 관련 조합식을 확인합니다. 메인에 별도 재료 조합 버튼을 상시 배치하지 않습니다.
- 장비를 유닛에게 드래그하거나 상세의 장착 동작을 사용할 수 있어야 합니다. 장비 아이콘/수량이 늘어나는 상태도 고려합니다.

7. 유닛 상세와 스킬

- PC는 오른쪽 유닛 상세/전투 기록 영역을 기준으로 합니다. 순위표는 이 영역과 독립됩니다.
- 내 유닛 상세는 어두운 파랑, 다른 유저/중립 적의 상세는 어두운 빨강 배경입니다. 내/적 텍스트를 반복하지 않습니다.
- 이름과 프로필을 알아보기 쉽게 표시하고, 내 유닛의 이름 오른쪽 판매 버튼은 프로필과 비슷한 크기입니다.
- 강화는 파란 별 반복, 레어도는 노란 별+등급 숫자, 가격은 ‘1G’처럼 간단히 같은 줄에 둡니다.
- 능력치는 체력 → 공격력 → 방어력 → 치명타 확률 → 치명타 피해 → 공격 속도 → 사거리 순서입니다. 한 줄 3개로 3/3/1 배치합니다.
- 체력은 초록 하트, 공격력은 빨강 총알, 방어력은 파랑 방패, 치명타 확률은 충격/가시 조각, 치명타 피해는 같은 아이콘+상향 화살표, 공격 속도는 시간/속도 아이콘, 사거리는 흰 양방향 화살표를 사용합니다.
- 공격 속도는 숫자와 등급을 함께 표시합니다. 예: ‘1.11’과 ‘빠름’.
- 구매 화폐인 골드(G)와 유닛별 스킬 자원인 코스트를 서로 구분해서 표시합니다.
- 공격 속성과 방어 속성은 각각 빨강/노랑/파랑/보라의 4개 체계이며 서로 구별할 수 있게 배치합니다.
- 현재 공격 표현은 위의 4속성 체계를 우선합니다. 총기 종류별 세부 차별화는 후속 계획입니다.
- 스킬은 액티브 왼쪽, 패시브 오른쪽의 같은 높이 2열 한 줄입니다. 각 칸에는 스킬 이미지·이름·종류·필요 코스트만 표시합니다.
- 스킬 칸의 PC 호버/모바일 터치로 상세 효과 툴팁을 엽니다. 여기에는 현재 코스트/재사용 상태 등 실제 필요한 상세를 넣을 수 있습니다. 스킬 상세를 별도의 중앙 모달로 만들지 않습니다.
- 툴팁에 유닛 이름을 반복하거나 ‘조건 대기’, ‘전투 불능’ 텍스트를 추가하지 않습니다.
- 발동 순간 스킬 칸은 잠깐 노랗게, 지속 효과가 유지되는 동안 초록 계열로 표시합니다.
- 주기 감소 설명은 ‘공격 주기 50% 감소’처럼 퍼센트와 단어로 표현합니다.
- ‘기본 가격’, ‘강화 장비 능력치’, 장비 장착 개수, 전장/대기석 위치 설명 같은 이미 제거한 보조 문구는 복원하지 않습니다.

8. 전투 화면·기록·보상

- 전투 중에는 캐릭터·체력바·공격 방향·피격을 우선합니다. 공격/이동 효과와 떠오르는 숫자가 전장을 읽는 데 방해되지 않게 합니다.
- 공격 속성 색은 공격측 효과와 피해 숫자, 방어 속성 색은 방어측 반응을 구분하는 데 사용합니다.
- 보호막 피해 숫자는 연한 파랑입니다. 보호막을 넘긴 피해는 보호막 피해 숫자와 원래 공격 속성 색의 체력 피해 숫자로 나눠 표시할 수 있어야 합니다.
- 스테이지 표시는 ‘스테이지 4-3’처럼 간단히 하고 전체 라운드 수를 반복하지 않습니다.
- 전투 기록은 버튼/탭에서 열고, 스테이지 기록은 5개씩 묶습니다. ‘현재’ 버튼과 매 전투 노란 알림 점은 추가하지 않습니다.
- 5회 전투마다 보상 선택 화면이 있습니다. 눈 버튼은 한 번 누르면 보상 내용을 숨기고 다시 누르면 복구하는 토글입니다.
- 보상을 숨겨도 눈 버튼은 같은 위치에 남습니다. 별도의 ‘라운드 보상 보기’ 버튼을 추가하지 않습니다.
- 보상을 숨긴 상태에서 허용되는 것은 아군/적 유닛 상세 조회입니다. 배치·구매·경험치·리롤·장비·전투 기록 등은 잠긴 상태로 보여줍니다.

9. 공통 조작과 모바일 대응

- 별도 ⓘ 도움말 버튼과 상시 노출되는 작은 도움말 문장을 추가하지 않습니다. 필요한 상세는 해당 정보 칸 자체의 호버/터치로 엽니다.
- 방 코드는 4글자이며 ‘방 코드’ 라벨을 사용합니다. 평소 블러 처리하고 눈 버튼으로 표시/숨김, 옆 버튼으로 복사합니다.
- 방 코드·효과 줄이기·정보 메뉴 같은 보조 기능은 전투 집중을 방해하지 않는 작은 영역으로 묶습니다.
- 순위 행·상점 상품·정보 메뉴는 최소 44×44px의 조작 영역을 확보합니다.
- 모달/툴팁/보상 눈 버튼은 화면 안에서 접근 가능해야 합니다. 긴 설명과 목록은 해당 영역 내부에서 스크롤합니다.
- PC 완성이 우선이며, 모바일 세로와 가로 모두 지원합니다. 세로 고정 안내를 사용하지 않습니다.
- 회전 시 방 연결·선택한 PC/모바일 모드·게임 진행·관전 대상·열어둔 유닛 상세가 유지되는 구조입니다.
- 모바일에서는 터치로 유닛 선택/배치/교환·관전 복귀·장비/기록 조회가 가능해야 합니다.

10. 후보 3개의 차이

다음 세 안을 같은 게임 상태·유닛·금액·플레이어 체력으로 비교해 주세요. 세 안은 패널 비율·정보 묶음·공간 사용에서 차이가 있어야 합니다.

A. 전장 집중형: 전장 크기와 전투 가시성을 가장 우선합니다. 조합/장비/상세 정보는 짧게 정리하고 필요한 내용으로 빠르게 이동하게 합니다.
B. 편성 효율형: 상점·대기석·경험치·조합·장비 사이의 시선 이동과 포인터 이동을 줄입니다. 준비 중 구매·합성·배치를 빠르게 판단하는 데 집중합니다.
C. 균형형: 전장 크기와 항상 확인할 정보를 균형 있게 유지합니다. 유닛 상세/전투 기록 탭과 독립 순위표의 관계를 명확히 하며 전술 게임의 통일된 패널/아이콘 체계를 보여줍니다.

오른쪽 독립 순위표, 8×8 전장, 12칸 정사각 대기석, 5개 상품 및 위의 확정 조작은 모든 안에서 유지합니다. 현재 패널 위치는 첨부 화면을 기준으로 하되, 간격/비율/여백/세부 정렬과 탭·접힘의 방식은 제안할 수 있습니다.
