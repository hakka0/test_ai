# 향후 기능 메모

## 유저별 프로필 사진

- 상태: 추후 추가 예정, 아직 구현하지 않음.
- 목적: 한 경기의 참가자를 사진으로 쉽게 구분하기.
- 적용 대상: 우선 참가자 순위표의 초상화. 현재는 닉네임 첫 글자를 표시하고 있음.
- 사진을 지정하지 않은 유저의 기본 초상화도 유지할 것.
- v0.20.68은 독립 순위 열의 이니셜 초상화와 넓은 PC의 닉네임/체력 마감만 개선했습니다. 실제 사진 업로드/저장은 여전히 후속 기능입니다.
- 업로드/선택 방식, 이미지 규격, 저장 위치와 유저 데이터 구조는 구현 단계에서 결정.
- 관련 위치: `client/ranking-ui.ts`, `shared/model.ts`, `shared/snapshot.ts`, 참가자 순위표 CSS.

현재 GUI 작업은 PC 화면을 우선 완성하며, 모바일 가로의 정보 창 위치 재설계는 후속으로 진행합니다.

## 6인 매칭과 여러 전장

- v0.20.60부터 전투 중 대기석 유닛만 판매할 수 있습니다. 6인 구현에서도 지속 보유 목록/공유 풀과 현재 전투 참가 ID를 분리하고, 대기석 판매·장비 반환이 진행 중인 전투를 바꾸지 않게 유지해야 합니다. 중앙 편성 수는 모든 관전 시점에서 전투 동안 숨깁니다.

- v0.20.54에 **1명 + 서버 봇 5명** PvP 연습을 추가했습니다. 실제 순환 매칭·독립된 세 전투·6명 미니언 도입부·체력/연속 골드·관전·탈락/공유 풀 반환을 검증했습니다. [사용 및 수정 방법](BOT_PRACTICE.md).
- 사람이 함께 접속하는 일반 방은 현재 2명입니다. 실제 사용자 6명의 입장·독립 재접속·탈락 순위는 후속 작업입니다. 봇의 구매/배치 AI도 임시 규칙이며 전략 고도화는 후속입니다.
- 첫 3회 미니언전은 유저별 독립 전장(`Fighter.arena`)입니다. 공격/스킬/경로/관전과 보상을 전장별로 분리하고, 중립 상대를 순위나 공유 풀에 넣지 않습니다. [보상/설정](MINION_ROUNDS.md).
- v0.20.52의 자동 복구는 같은 플레이어 자리를 실제 시간 5분 동안 예약합니다. 6인 서버에서도 각 유저의 자리/토큰을 독립 보관하고, 접속자가 있는 방을 시간 경과만으로 삭제하지 않는 규칙을 유지해야 합니다. 현재 방은 메모리에만 저장하므로 서버 재시작 후 경기 복원은 별도 영속 저장 기능이 필요합니다.
- v0.20.49는 2인 PvP에서 준비 → 5초 매칭 → 전투 흐름을 지원합니다. v0.20.55부터 준비·매칭에서도 배치/대기석을 공개하며 대전 쌍만 전투 시작에 공개합니다. 추후 6인 서버에서도 이 공개 시점과 관전 중 본인 상점 구매 규칙을 유지해야 합니다.
- v0.20.50부터 전투·결과의 구매 합성은 보류하고 다음 준비에서 일괄 처리합니다. 6인 서버에서도 준비 진입의 합성 → 상점 갱신/보상 순서와 보류 중 실제 대기석 용량 검증을 유지해야 합니다.
- v0.20.45의 실시간 관전은 공개 `Snapshot.battlePairs`로 각 전장의 두 참가자를 구분합니다. 배열 순서는 해당 전장의 좌표 기준이며, 순위 정렬 순서로 바꾸지 않습니다.
- 다인 서버 구현 시 실제 매칭 쌍과 각 쌍의 공개 전투 유닛·이벤트를 함께 전송해야 합니다. 유닛 ID와 이벤트 ID도 여러 전장에 걸쳐 구분해야 합니다.
- 클라이언트는 선택한 참가자의 대전 쌍만 표시합니다. 기존 6인 UI 사본 검사와 v0.20.54의 실제 1명+봇 5명 서버 검사는 구분합니다.

- 공유 유닛 풀은 참가자 배열 전체에서 종류당 30장을 계산합니다. 봇 연습에서는 라운드 종료에 탈락자의 보유 유닛·상점·미선택 보상을 해제하며 정상 시작 상태의 6인 경기 완주에서도 예약 수량을 검증했습니다.

## 수치 방어력과 피해 계산식

v0.20.38에서 후속 치명타 비교의 2안(길드워2 직접 피해 구조)을 채용했습니다. 일반 유닛 방어력 8~10, 탱커 12/14를 배정하고 체력·공격력·주기를 조정했습니다. 기본 공격·공격 스킬과 배리어에 실제 적용합니다. [적용 수치와 전투 검증](COMBAT_BALANCE.md). 방어력·치명타를 주는 신규 장비의 카탈로그 추가는 추후 작업이며 데이터 보정 경로는 지원합니다.

## 유닛별 치명타 확률·치명타 피해

v0.20.38에서 전원 기본 확률 10%, 기본 총 피해 150%(1.5배)로 적용했습니다. 유닛·장비·스킬별 수치 수정이 가능하며 서버가 타격마다 판정합니다. 현재 총기 종류별 위력·모션은 여전히 공통이며 종류별 분화는 후속 작업입니다. [직접 수정 매뉴얼](CHARACTER_CUSTOMIZATION_GUIDE.md).

## 조합 상위 단계와 캐릭터 추가

v0.20.58에서 요청에 따라 임시 유닛 12종을 추가했습니다. 총 18종, 계열당 6종이므로 실제 4·6종 효과를 시험할 수 있습니다. 같은 종류의 중복/강화/대기석을 제외하는 기존 집계를 유지합니다. v0.20.59는 `현재 인원 → 이름 → 2/4/6` 순서이며 현재 적용되는 가장 높은 단계와 효과 값 하나만 흰색, 나머지는 회색입니다. v0.20.63은 비활성을 원래 색으로 두고, 2종/4종/6종을 브론즈/실버/골드의 밝은 배경과 정적 발광으로 표시합니다. 퍼플의 스타일·단계 연결은 향후 4단계용으로 준비했으며 실제 네 번째 기준/효과는 미구현입니다. 임시 능력치/속성/스킬 조합과 구분용 그림을 최종 캐릭터·밸런스로 다듬는 일은 후속 작업입니다. [18종과 디버깅 방법](EXPANDED_UNITS.md), [조합 표시 규칙](SYNERGY_TIERS.md).
