# PvP 연습 · 봇 5명 (0.20.60)

`npm start`로 서버를 다시 실행한 후 홈의 **PvP 연습 · 봇 5명**을 누릅니다. 내 유저 1명과 서버가 조작하는 봇 5명이 즉시 시작합니다. 다른 브라우저나 친구의 참가가 필요하지 않습니다. 방은 실제 접속자 1명으로 잠깁니다.

v0.20.58은 총 18종(계열마다 6종)과 **수호/정찰/비전 6종 / 전체 18종** 시작 상태를 제공합니다. 6종을 출전시키고 나머지 12종을 대기석에 두므로 교환으로 2·4·6종 효과를 반복 검증할 수 있습니다. [목록과 자세한 사용법](EXPANDED_UNITS.md).

v0.20.60부터 전투 중 내 대기석은 판매 버튼/상점 드래그로 판매할 수 있습니다. 출전 유닛은 보호하며 전투 중 구매한 새 대기석도 판매 가능합니다. 중앙 편성 수는 전투·관전 중 숨기고 결과·준비에서 표시합니다. 전투를 일시정지해 판매 전후의 전투 유닛이 유지되는지 확인할 수 있습니다.

## 진행과 관전

- 첫 3번은 각자의 미니언전이며 기존 처치 보상을 지급합니다.
- 이후 준비 → 5초 매칭 → 세 쌍의 독립된 1:1 전투 → 결과 순서입니다. 6명 모두 생존하면 5회 동안 서로 다른 상대와 싸웁니다.
- 봇은 매 준비에 실제 골드로 구매·리롤·경험치 구매를 하고, 같은 유닛을 합성하고, 배치와 완성 장비 장착을 합니다. 전술 AI는 임시 구매/배치 규칙입니다.
- 순위표의 체력은 실제 경기 값입니다. 준비·매칭 중에도 다른 참가자의 배열과 대기석을 공개합니다. 실제 대전 쌍은 전투부터 공개합니다. 순위를 누르면 그 참가자가 싸우는 양쪽 유닛과 대기석을 조회합니다. 관전 중에도 내 상점에서 구매할 수 있습니다.
- 전투별 체력 피해·승리/연속 골드는 각 쌍에 따로 적용합니다. 기록은 본인의 실제 상대와 기여도만 표시합니다.
- 탈락자의 유닛·상점·미선택 보상을 공유 풀에 반환합니다. 탈락 후 남은 봇을 관전할 수 있으며 마지막 생존자 또는 40라운드에서 끝납니다. 홀수 생존자 중 한 명은 해당 라운드를 쉬며 체력/연속 기록/승리 골드는 변하지 않습니다.

## 혼자 디버깅하기

정보 창의 **디버깅** 탭 → **개발 디버깅**에서 다음 기능을 사용합니다. 이 전용 방은 `DEBUG_GAME` 설정 없이도 도구를 제공합니다. 일반 친구 대전에는 적용하지 않습니다.

1. **일시정지** 후 **0.1초 진행 / 1초 진행**으로 전투를 관찰합니다.
2. **다음 단계**로 준비·5초 매칭·실제 전투 종료·결과를 차례로 넘깁니다.
3. **배속**으로 1·2·5·10배 진행을 선택합니다.
4. **피버타임 · 방패 대결**로 20초 이후의 최대 15초 피버 강화도 시험할 수 있습니다. [전투 수치](COMBAT_FEVER.md).
5. **시작 상태**의 **처음 / 중반 / 후반 / 최대** 등은 6명을 모두 설정하고 바로 PvP를 시험합니다. **미니언전 시작**은 도입부 3회를 포함합니다. 프리셋은 명시적인 시험용 유닛/장비를 제공하므로 일반 구매와 별개입니다.
6. **상태 저장 / 저장 상태 복원**은 모든 참가자, 매칭 쌍, 전투/결과와 게임 시계를 함께 복원합니다. 탈락한 경우에도 프리셋으로 새 시험을 시작할 수 있습니다.

프리셋이나 복원은 현재 연습 경기의 상태를 바꿉니다. 새로고침과 일시 단절에는 기존 5분 재접속을 적용하며 같은 방으로 복귀합니다. 서버 재시작 후에는 새 방을 만듭니다.

## 수정 위치와 범위

| 대상 | 파일 |
|---|---|
| 진입 버튼 / 연결 옵션 | `client/main.ts`, `client/net.ts` |
| 봇 5명 생성 / 1명 접속 제한 / 디버깅 허용 | `server/GameRoom.ts` |
| 상대 순환 / 봇 구분 | `shared/bot-practice.ts` |
| 구매·배치·장착 AI / 독립 전투 / 탈락 / 결과 | `shared/engine.ts` |
| 관전 공개 데이터 / 비공개 시점 | `shared/snapshot.ts`, `client/scouting.ts` |
| 6명 프리셋 / 저장·복원 | `server/debug.ts` |

실제 서버가 실행하는 **1명 + 봇 5명** 모드입니다. 기존 순위표 UI용 6인 사본과 구분합니다. 사람끼리 접속하는 방은 계속 **2명**이며 실제 사용자 6명의 입장·재접속·탈락 순위 확장은 후속 작업입니다.

검사: `npm test`, `npm run test:network`, `npm run test:bot-practice:browser`. 화면 측정과 캡처: [results.json](screenshots/bot-practice-0.20.54/results.json).
