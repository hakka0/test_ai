# 0.15.0 모바일 화면

세로 화면에서는 전투판을 위에, 대기석/상점을 하단 고정 창의 두 줄에 함께 표시합니다. 전투판과 고정 창이 겹치지 않도록 실제 창 높이를 측정합니다. 스크롤해도 하단 창이 유지되며 전투 중 자동으로 접히지 않습니다.

## 하단 조작

- 레벨·출전 수·골드·경험치와 준비 완료·리롤·경험치 구매를 표시합니다.
- 대기석 12칸은 가로 목록입니다. 좌우 화살표로 이동합니다. 유닛 카드의 손가락 이동은 배치 드래그에 사용하므로 카드 위에서 스와이프할 필요 없이 화살표로 끝의 칸까지 접근할 수 있습니다.
- 상점 5칸은 동시에 표시합니다. 그림·이름·가격을 우선 표시하고 부가 정보는 상세 창에서 확인합니다.
- 유닛을 선택하면 이름과 상세·장비·대기석 복귀·선택 해제(×) 버튼이 나타납니다. 선택 해제로 전투판 공간을 다시 확보합니다.
- 선택하지 않은 상태에서 드래그를 시작하면 드래그가 끝날 때까지 조작 줄의 크기를 유지합니다. 선택 때문에 목표 칸이 이동하는 것을 막습니다. 화면 회전·터치 취소·모드 변경 시 배치를 취소합니다.
- **접기**는 대기석/상점만 숨깁니다. 다시 펼치기로 복원합니다. PC와 모바일의 접힘 상태는 현재 페이지에서 각각 유지합니다.

화살표·구매·주요 조작은 44px 이상의 터치 영역을 사용합니다. 보상/유닛 상세/정보 창은 native dialog로 열며 배경 조작을 차단합니다. 로비에서는 하단 창도 비활성화됩니다.

## 정보 표시

상단에는 스테이지·진행 단계·시간·양측 이름/체력을 모았습니다. **기록** 버튼으로 라운드 진행표와 승패·체력 감소·기여도를 확인합니다. **정보** 버튼은 장비/제작 창을 열며 탭으로 조합·수입·방/연결·도움말 등을 확인할 수 있습니다. 처음 연 버튼으로 닫은 뒤 초점이 돌아갑니다.

유닛 상세/장비는 기존 팝업을 사용합니다. 보상이나 최종 결과가 열리면 정보 창을 닫아 겹치지 않게 합니다. 보상 팝업의 눈 버튼을 누르는 동안 팝업과 배경을 투명하게 하고, 손을 떼거나 회전/취소하면 복원합니다.

## 화면 크기

초기 준비 화면, 선택 유닛 없음 기준의 측정입니다. 선택·보상 상태와 글 내용에 따라 하단 높이가 바뀌며 그때마다 다시 측정합니다.

| 화면 | 전투판 | 하단 고정 창 | 전투판 전체 |
|---|---:|---:|---|
| 390×844 | 376px | 약 274px | 표시 |
| 320×740 | 306px | 약 274px | 표시 |
| 360×640 | 216px | 약 274px | 표시 |
| 414×896 | 400px | 약 274px | 표시 |
| 768×1024 | 480px | 약 274px | 표시 |
| 844×390 | 180px | 약 141px | 내부 스크롤/접기 |
| 480×320 | 180px | 192px 상한 | 전투판·하단 창 내부 스크롤/접기 |

폭 620px 이상이고 높이 540px 이하인 가로 화면은 하단 대기석과 상점을 좌우에 배치합니다. 매우 낮은 창에서는 전투판의 최소 크기를 유지하므로 내부 스크롤이나 접기가 필요합니다. 모바일 모드는 큰 화면에서도 최대 폭 680px를 사용합니다. PC로 직접 전환하면 기존 PC 배치를 사용합니다.
