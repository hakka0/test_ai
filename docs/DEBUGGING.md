# 개발 디버깅

## 실행

```bash
npm ci
npm run dev:debug
```

PowerShell은 `npm.cmd`를 사용하세요. 표시되는 Vite 주소로 접속하여 혼자 연습하기를 선택하고 전장 아래 개발 디버깅 패널을 엽니다. 이 명령은 개발 서버와 클라이언트를 함께 시작하며 DEBUG_GAME=1을 설정합니다. 프로그램 종료는 Ctrl+C입니다.

보통 실행 명령 `npm run dev`/`npm start`는 환경에 DEBUG_GAME=1을 직접 넣지 않는 한 패널을 제공하지 않습니다. NODE_ENV=production에서는 이 값을 무시합니다. 일반 대전·미등록 접속·봇은 서버 디버깅 조작 권한이 없습니다. 서버의 허용 검사와 클라이언트의 패널 숨김을 함께 사용합니다.

## 도구

| 조작 | 동작 |
|---|---|
| 1/2/5/10배 | 동일한 전투 규칙으로 서버 게임 시간을 빠르게 진행 |
| 일시정지/계속 | 게임 시간·마감·전투를 멈추거나 재개 |
| 0.1초/1초 진행 | 일시정지 상태에서 지정한 게임 시간만 진행 |
| 다음 단계 | 준비→전투, 전투→결과, 결과→다음 준비/종료. 전투 실제 종료 시점에서 멈춤 |
| 시작 상태 | 처음(1레벨), 중반(13라운드 7레벨), 후반(19라운드 8레벨), 최대(25라운드 10레벨), 합성(기사 2개·3레벨), 조합(7라운드·6레벨·6종) |
| 상태 저장 | 현재 서버 Match와 게임 시각을 현재 방 메모리에 저장 |
| 저장 상태 복원 | 저장한 Match·시각을 복원하고 일시정지 |

일반 프리셋은 출전 정원에 맞는 유닛·골드·체력·장비를 준비합니다. 중후반에는 강화 유닛을 미리 구성하며 프리셋 생성 자체로 합성을 발생시키지 않습니다. 합성 프리셋은 전장 기사 1개, 대기석 기사 1개·마법사 1개와 장비를 준비합니다. 상점 첫 칸의 기사를 사면 전장 기사가 2성으로 강화되고 두 기사의 장비가 합쳐집니다. 상대도 같은 성장 단계로 맞춥니다. 프리셋/복원 뒤에는 클라이언트의 선택·드래그·전장 표시를 초기화합니다. 상점과 유닛 ID를 새로 발급하고 프리셋 이전 구매/경험치 요청 버전을 무효화합니다.

저장 상태는 하나이며 서버 재시작·방 삭제 시 사라집니다. 저장하는 것은 서버 게임 상태이며 브라우저 패널, 미래 난수 결과, 인터넷 지연까지 저장하는 리플레이는 아닙니다. 전투 계산은 결정적이지만 복원 후 새 상점 리롤은 달라질 수 있습니다.

## 시간 분리

GameClock은 실제 monotonic 시각을 게임 시각으로 변환합니다. 입력 마감, 전투, 스킬, 결과 표시는 게임 시각을 사용합니다. 클라이언트는 snapshot의 gameNow/serverNow/timeScale로 같은 게임 시간을 보간합니다. 정지 시 scale=0입니다.

ping RTT, 재접속 60초, 요청 빈도 제한, 방 수명은 실제 시간을 사용합니다. 배속 변경이 연결 유예시간이나 악성 요청 제한을 바꾸지 않습니다. 고정 100ms 전투 계산은 그대로이며 전송 간격을 10배로 줄이는 방식이 아닙니다.

## 권장 흐름

1. 후반 프리셋 선택 후 일시정지합니다.
2. 유닛·장비를 설정하고 상태를 저장합니다.
3. 다음 단계로 전투를 시작하고 0.1초/1초 진행으로 문제를 확인합니다.
4. 저장 상태를 복원해 같은 전투를 반복합니다.
5. 전체 흐름은 10배 또는 `npm run simulate`로 확인합니다.
6. 모바일 조작감·실제 지연·정상 속도 표현은 마지막에 1배로 확인합니다.

## 합성 회귀 확인

1. 일시정지 → 합성 프리셋 → 상태 저장.
2. 상점 첫 칸 구매: 10→9골드, 전장 기사 2성, 대기석 2→1명, 장비 2개 확인.
3. 상세 창 판매 가격 3골드 확인. 다음 단계로 전투를 시작하면 강화 최대 체력 528(468+장비60)입니다.
4. 저장 복원 후 같은 구매를 반복하거나 강화 기사를 판매합니다. 판매 시 장비가 인벤토리에 반환됩니다.
5. 3성 연쇄·만석·장비 초과 반환은 tests/merge.test.ts에서도 검증합니다.

## 조합 회귀 확인 (0.8.0)

1. 일시정지 → 조합 · 6종 → 시작 상태 적용. 양쪽 6레벨, 서로 다른 6종 강화 1성, 세 계열 활성입니다.
2. 내 계열 파트너를 대기석으로 회수하면 해당 조합이 비활성화됩니다. 상대는 출전 목록만으로 조합을 봅니다.
3. 전투 시작 시 루멘 최대 체력 299, 노바 시작 보호막 85(비전30+별의 가호20+장착 부적35)를 확인합니다. 시너지 보호막은 공격으로 감소하므로 일시정지 상태에서 확인하세요.
4. 파트너가 죽어도 시작 조합을 유지합니다. 저장→1초 진행→복원→재접속으로 같은 Fighter 체력·보호막·스킬 상태를 재현합니다.
5. 출전 한도·중복 종류·신규 스킬·합성·판매·공개 범위는 tests/synergy.test.ts, 실제 통신은 tests/debug.network.test.ts에서 검사합니다.

## 보상·제작 프리셋 (0.9.0)

**보상 · 5라운드 / 재료 4개**를 적용하면 5라운드 보상과 강철 2개·수호 천·결정을 즉시 얻습니다. 일시정지 후 상태 저장, 후보 선택/제작, 상태 복원으로 반복 검사하세요. 제작한 장비는 선택 유닛의 장비 관리에서 장착할 수 있습니다.
