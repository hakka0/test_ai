# 0.17.0 장비 드래그 장착

PC는 왼쪽 장비 패널을 바로 사용합니다. 모바일/폭 700px 이하 PC 창은 전장 왼쪽 **장비** 버튼으로 패널을 펼칩니다. 장비 카드에서 시작해 받을 내 유닛까지 끌고, 대상 이름과 초록색 강조를 확인한 뒤 놓으세요. 전장과 대기석 모두 가능합니다. 장비마다 이름·등급·설명을 확인할 수 있습니다.

드래그 중에는 장비 이름과 **대상 유닛 이름·강화 등급**을 손가락 위에 표시합니다. 대상 유닛의 칸/카드를 강조하고, 장착 가능하면 장비 수/한도와 '놓으면 장착'을 표시합니다. 장착 불가 대상은 빨간색과 사유를 표시하며 드롭해도 변경하지 않습니다. 대상은 드래그를 시작하기 전에 선택한 유닛과 관계없이 드롭 위치로 정합니다.

| 드롭 대상/상태 | 결과 |
|---|---|
| 준비 완료 전 내 유닛, 빈 장비 슬롯 | 해당 유닛에게 장착 |
| 내 유닛의 장비 2개 | 한도 초과 표시, 변경 없음 |
| 상대 유닛/빈 칸/창 밖 | 유효한 대상 없음, 변경 없음 |
| 조합 재료 | 제작 후 장착 안내, 변경 없음 |
| 준비 완료 이후/전투/마감/연결 해제 | 장착 제한, 변경 없음 |
| 취소/Escape/회전/창 크기 변경/모달 열기 | 드래그 취소 |

모바일에서는 드래그 중 장비 패널을 흐리게 하고 패널의 포인터 판정을 해제합니다. 전장 폭과 하단 창 높이는 유지하므로 패널에 가려졌던 유닛에도 타게팅할 수 있습니다. 실제 장착은 서버가 최종 검증합니다. 응답 전 중복 거래는 기존 거래 잠금으로 차단합니다.

드래그 대신 **장비를 선택 → 받을 유닛 클릭**도 가능합니다. 키보드로 장비에 초점을 맞추고 Enter/Space, 이어서 유닛에 초점을 맞추고 Enter를 누릅니다. 취소 버튼/Escape로 장비 선택을 해제합니다. 준비/경험치/정보/탭 조작이나 패널 접기·모드 변경 시 선택을 취소합니다. 재료 카드를 선택하면 설명을 표시하며 **재료 조합** 버튼으로 제작 관리 화면을 바로 엽니다.

착용 중인 장비는 해당 유닛 상세 팝업에서 해제하거나 이동합니다. 해제하면 왼쪽 목록으로 돌아옵니다. 장비 패널에는 미장착 장비와 조합 재료를 표시합니다. 아주 낮은 창에서 패널이 작으면 하단 내용을 접어 공간을 확보한 뒤 패널 내부를 스크롤하세요.
