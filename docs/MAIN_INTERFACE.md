# 메인 화면 정보 배치

## v0.21.1 블루 아카이브 20인 테스트

- 홈에서 **블루 아카이브 20인 테스트**를 선택하면 레벨 10, 30골드, 전장 8명, 대기석 12명으로 시작합니다. PC에서는 유닛 선택과 칸 클릭으로 배치합니다. 모바일에서 대기석을 탭하면 상세가 열리며, 닫으면 선택한 유닛을 전장에 배치할 수 있습니다. 최대 출전 인원은 10명입니다.
- 전장은 배치 시 아군의 뒷모습과 상대의 앞모습을 표시합니다. 전투 중에는 상대 위치에 따라 6방향 프레임을 선택합니다. 상점·대기석·유닛 상세에는 정면 이미지, 유닛 상세에는 해당 능력치와 자동 스킬을 표시합니다.
- 이 모드는 사용자 1명과 연습 상대 1명이 플레이합니다. 일반 2인 대전과 1명+봇 5명 PvP 연습은 홈에서 따로 선택합니다.

PC 왼쪽 열은 출전 조합 → 보유 장비 순서입니다. 전투 중 바로 확인할 정보인 출전 조합은 정보·전투 기록 팝업에 넣지 않습니다. 좁은 PC 화면과 모바일에서는 전장 위에 조합을 압축 표시하며, 장비 버튼은 그 아래에 놓습니다.

## 0.20.72의 차분한 파스텔 색상

흰색 위주의 면을 회녹색·회청색으로 낮춰 밝은 화면의 눈부심을 줄였습니다. 전장과 대기석·상점·상세뿐 아니라 로비, 정보/제작/보상/전투 기록, 도움말과 스킬 SVG 13개에도 적용합니다. 반투명 필터 대신 실제 배경색과 글자색을 조정해 캐릭터 그림은 본래 색을 유지합니다.

| 역할 | 색상 |
| --- | --- |
| 전체 바탕 | 회녹색–회청색 `#d1dad7` → `#c5d2d4` |
| 공통 패널 | 부드러운 세이지 `#dce3df` |
| 안쪽 면 / 낮은 면 | `#d1dcdb` / `#c5d2d4` |
| 준비·주요 버튼 | 파스텔 민트 `#adc7bd`, 짙은 글자 `#25464d` |
| 본문 / 보조 글자 | `#21394c` / `#415662` |
| 조합 단계 | 브론즈 `#ead4bd`, 실버 `#ccd6df`, 골드 `#e9ddac`, 퍼플 `#dacee6` |

선택은 청록색 테두리·역삼각형·진한 현재 단계로 표시합니다. 승리/효과 유지는 세이지, 패배/상대는 더스티 로즈로 구분하며 작은 가격·등급·상태 글자도 새 배경에 맞춰 어둡게 조정했습니다. PC의 2단 운영 영역과 대기석 정렬, 모바일 회전 배치는 기존 구조를 유지합니다. 팔레트는 `client/interface-theme.css`, 전장 면/이름표는 `client/board.ts`에서 관리합니다.

## 0.20.71의 대기석 정렬 수정

- PC 하단 대기석 줄에 선택 표시를 위한 상단 여백 12px이 빠져 카드가 프레임 아래로 밀려 나던 문제를 수정했습니다. 고정 86px 대신 `카드 크기 + 46px`(제목 16px + 간격 4px + 표시 여백 12px + 세로 패딩 12px + 테두리 2px)을 사용합니다. 1400px PC는 98px, 1024px PC는 90px이며 골드·성장 칸과 위/아래 경계를 맞춥니다.
- 선택한 대기석 카드의 역삼각형은 카드 바깥의 예약 여백에 표시합니다. 카드가 이 표시를 자르지 않도록 하고, 대기석 스크롤 영역의 12px 여백은 유지합니다. 모바일도 같은 선택 표시를 사용합니다.
- 2단 운영 영역의 위치와 대기석 12칸·구매/판매 규칙은 그대로입니다. 수정 위치는 `client/interface-theme.css`입니다.

## 0.20.70의 전체 밝은 테마와 시안 배치 반영

색상만 차용했던 0.20.69에서 더 나아가, 앞서 확인한 첨부 시안의 상태 줄·운영 영역·순위 행 구조를 실제 DOM 배치에 반영했습니다.

| 영역 | 현재 배치와 색상 |
| --- | --- |
| PC 상단 | 전장 안에 있던 라운드·단계·시간·정보/전투 기록을 네 열 전체를 가로지르는 공통 상태 줄로 이동 |
| PC 하단 | 골드/성장·대기석이 위, 리롤·상품 5개가 아래인 2단 운영 영역. 준비 버튼은 오른쪽 끝 |
| 넓은 PC 순위 | 오른쪽의 독립된 170px 열. 초상화 옆에 이름·레벨·체력을 표시하는 가로형 행 |
| 유닛 상세 | 큰 초상화/이름 → 능력치 6개 3열×2행 → 사거리 한 줄 → 두 스킬 → 착용 장비 |
| 공통 색상 | 흰색·옅은 회청색 패널과 청록 강조. 대기석·상점·스킬·장비·상세·툴팁·보상·제작·기록·로비·하단 설정도 같은 팔레트 |

- PC의 상태 줄과 대기석은 같은 DOM 요소를 재배치합니다. `client/pc-layout.ts`의 `placeStatus()`가 `tactical-desktop`을 적용하고, 모바일/낮은 가로 화면에서는 상태 줄과 대기석을 원래 전장 영역으로 돌립니다. 게임 상태/연결/선택한 관전 대상은 다시 생성하지 않습니다.
- 1024px PC에서는 132px 조합/장비 열·270px 상세·64px 압축 순위를 사용합니다. 대기석 12칸은 정사각형이며 최소 44px, 가용 폭보다 목록이 길어지면 내부 가로 스크롤을 사용합니다. 상점 구매/판매 드롭 영역과 대기석을 분리해 판정합니다.
- 상품·대기석의 레어도는 어두운 채움 대신 기존 의미색의 테두리로 구분합니다. 조합은 밝은 브론즈/실버/골드 틴트와 왼쪽 선으로 단계를 구분하고, 현재 단계 수치 하나를 어둡고 굵게 강조합니다. 네 번째 퍼플은 렌더링 준비만 되어 있으며 실제 효과는 미구현입니다.
- 공격/방어·능력치 아이콘의 의미색은 밝은 배경에서 읽히는 진한 계열색을 사용합니다. 전장 이름표와 스킬 SVG 13개도 밝은 바탕으로 맞췄습니다. 캐릭터 그림과 전투 규칙은 그대로입니다.
- 색/배치 마감은 `client/interface-theme.css`, PC 재배치는 `client/pc-layout.ts`, 순위 레벨 표시는 `client/ranking-ui.ts`, 전장 이름표/게이지는 `client/board.ts`, 스킬 그림은 `public/skills/*.svg`에서 조정합니다.
- 순위는 유닛/전투 기록 위에 쌓지 않습니다. 모바일 가로 정보 창의 별도 위치 재설계는 여전히 후속이며 기존 정식 지원 배치를 유지합니다. 프로필 사진 업로드도 후속입니다.

이하 내용은 이전 버전 기록입니다.

## 0.20.68의 통합 전술 UI

- 외부 시안의 균일한 패널/카드 마감과 캐릭터 중심 표현을 기존 전장 중심 구조에 적용했습니다. 네이비/차콜 바탕, 민트와 금색 강조, 공통 16px 패널/10px 조작 모서리, 얇은 테두리·정적인 그림자를 사용합니다. 왼쪽 조합/장비, 중앙 8×8 전장과 12칸 대기석, 오른쪽 유닛/전투 기록 및 독립 순위 열, 상품 5개의 운영 콘솔을 유지합니다.

- 대기석의 초상화가 정사각형 칸을 넓게 채우며 이름은 아래에 짧게 겹칩니다. 빈칸과 점유 칸의 크기는 같습니다. 새 캐릭터 일러스트나 프로필 업로드 기능은 추가하지 않고 기존 에셋을 사용합니다.

## 0.20.66의 상점 조작과 도움말 정리

연승·연패 2~3회 +1G, 4회 +2G, 5회 이상 +3G는 **전투 종료 직후** 지급합니다. 다음 준비에서는 기본 수입·이자만 지급해 중복을 막습니다. 연속 표시의 PC 설명과 수입 도움말에도 기준을 제공합니다. [보상표와 직접 조절할 위치](MINION_ROUNDS.md).

## 연결 복구

v0.20.52부터 일시 단절 시 서버가 같은 플레이어 자리를 실제 시간 기준 **5분** 동안 보관하고 클라이언트가 자동으로 재접속합니다. 응답이 15초 이상 없는 연결도 복구 대상으로 판단합니다. 네트워크가 돌아오거나 창에 초점을 맞추거나 모바일에서 앱 화면으로 복귀하면 즉시 상태를 확인하고 재시도 대기를 깨웁니다. 정상 연결 중에는 방을 10분/90분 경과만으로 삭제하지 않으며, 접속자와 재접속 예약이 모두 없어지면 방을 정리합니다.

게임 화면에는 복구 중 안내를 유지하고 연결이 돌아오면 복구 완료를 잠시 표시합니다. 상세 창이 열려 있으면 그 안에도 안내합니다. 상점 구매·배치·판매 등 서버에 보내는 조작은 복구 중 잠깁니다. 같은 방 코드·플레이어 ID로 복귀하므로 현재 유닛·골드·상점·전투 상태를 이어받으며, 현재 페이지의 관전 대상·선택 유닛과 화면 모드도 유지합니다. **경기는 단절 중에도 서버에서 계속 진행**하므로 복귀 시 최신 상태를 받습니다.

같은 탭을 새로고침해도 저장된 재접속 토큰으로 재시도합니다. 홈에서 복구 대기 중 새 연습/방 생성/참가를 선택하면 이전 복원을 취소하며 새 방을 덮어쓰지 않습니다. 명시적 로비 복귀는 자동 복구를 취소합니다. 이미 삭제된 방·만료한 토큰은 재시도를 끝내고 한국어로 안내합니다. 서버는 메모리에 경기를 저장하므로 **서버 프로세스 재시작으로 사라진 방은 복구할 수 없습니다**. 정상 복구에는 별도 버튼이나 새 방 코드 입력이 필요하지 않습니다.

서버와 클라이언트의 유예 시간은 `shared/connection-policy.ts`, 서버 자리 예약은 `server/GameRoom.ts`, 자동 복구·응답 감시·토큰 처리는 `client/net.ts`에서 조정합니다. 사람끼리 접속하는 방은 2인이고, 별도 PvP 연습 방은 1명+봇 5명입니다.

## 유닛 합성 시점

v0.20.50부터 전투·라운드 결과 중 구매한 유닛은 각각 빈 대기석에 추가합니다. 같은 종류·강화 등급 3개를 모아도 기존 유닛 ID·성급·장비·전장 배치를 유지하고 합성 알림도 띄우지 않습니다. **다음 준비 진입 시** 모인 모든 종류의 합성을 처리하며, 여러 묶음과 2성→3성 연쇄 합성도 한 번에 적용합니다. 전장 유닛 우선 보존·장비 2개 유지/초과 반환·원본 수량 보존 규칙은 같습니다.

준비 중 구매·보상은 기존처럼 즉시 합성합니다. 준비 진입의 합성은 상점 갱신·보상 추첨보다 먼저 처리하므로 그때 완성한 3성 종류는 본인 상점·보상에서 제외합니다. 합성을 보류하는 전투·결과 중에는 **빈 대기석이 필요**하며 만석이면 합성 가능한 종류도 구매할 수 없습니다. 판매한 원본은 다음 준비의 합성에서 제외합니다. 결과 화면과 경기 종료에서는 자동 합성하지 않습니다. 강화 별과 선택 표시도 준비에서 실제 합성된 뒤 갱신됩니다.

## 판매와 공유 유닛 풀

준비 완료 전 준비 단계와 라운드 결과 시간에 내 전장·대기석 유닛을 상점 상품 영역으로 드래그하면 붉은 판매 영역이 나타납니다. ‘판매’는 상품 영역의 가로·세로 중앙에 표시합니다. v0.20.51부터 드래그 이미지와 포인터 사이의 간격은 상점 진입·이탈과 관계없이 일정하게 유지합니다. 판매 영역에서는 이미지의 투명도를 높여 글자를 읽을 수 있게 하며, 영역에서 나오면 원래 투명도로 복원합니다. 놓으면 해당 유닛을 즉시 판매하며 취소·다른 영역 드롭·화면 회전·페이즈 전환 때 판매 표시를 정리합니다. 기존 판매 가격(원본 1/3/9장 × 레어도 가격)을 지급하고 장비를 보관함에 반환하며 공유 풀에도 원본 수량이 돌아갑니다. 관전·상대 유닛·보상 확인 모드·준비 완료한 준비 단계·매칭·마감·대기·경기 종료의 판매는 차단합니다. 경험치·리롤·준비 완료 영역은 판매 영역에 포함하지 않습니다.

v0.20.60부터 전투 중에는 **대기석 유닛만 판매**합니다. 상세 상단·하단·정보 패널과 상점 드롭이 대상 유닛별로 같은 권한을 사용합니다. 출전 유닛과 타인 유닛의 직접 판매 요청은 보유 목록·골드·장비·공유 풀을 바꾸지 않습니다. 준비 완료 전과 결과에서는 기존처럼 전장/대기석 판매를 허용합니다. 결과에서 판매한 유닛은 완료된 전투 기록/고정 유닛 정보에는 남고 다음 준비에서 제외됩니다. 전투 중 배치·자리 교환·대기석 회수는 잠깁니다.

오른쪽 유닛 정보의 이름 오른쪽과 상세 창 상단 이름 오른쪽에 가격이 적힌 판매 버튼을 제공합니다. 오른쪽 버튼은 초상화와 같은 48×56px, 상세 창 버튼은 초상화와 같은 58×68px입니다. 새 버튼은 바로 판매하며 기존 하단의 판매 확인 조작도 유지합니다. 장비 상세에서 ‘장착할 유닛 선택’을 눌렀을 때 장비 아래에 아이템 이름·효과를 반복 표시하지 않습니다. 장비 카드 선택 표시와 취소 버튼은 유지합니다.

모든 유저가 종류당 30장의 공유 유닛 풀을 사용합니다. 전장·대기석 보유분은 강화 1/2/3성당 원본 1/3/9장으로 계산하며 합성해도 풀에 돌아가지 않습니다. 판매하면 원본 수량이 돌아옵니다. 미구매 상점 상품과 선택 대기 중인 유닛 보상도 수량을 예약합니다. 리롤·다음 준비의 상점 교체와 다른 보상 선택은 미사용 예약을 반환합니다. 각 종류의 남은 수량에 비례해 상점 추첨 확률이 달라지며 보상은 기본 레어도 확률에 각 등급의 남은 원본 비율을 가중하고, 그 안에서 남은 종류를 추첨합니다. 해당 등급에 한 종류만 있어도 보유량 증가에 따라 확률이 줄어듭니다. 후보가 없는 레어도는 제외해 확률을 재분배합니다.

3성을 완성한 종류는 그 유저 본인의 상점·보상에서 제외합니다. 이미 남아 있던 본인 상품은 다른 종류로 바꾸고, 이미 존재하는 같은 종류 보상 후보는 제거합니다. 다른 유저는 남은 공유 수량으로 계속 얻을 수 있습니다. 3성 유닛을 판매해 해당 종류의 3성이 없어지면 다시 추첨 대상이 됩니다. 더 뽑을 종류가 없으면 상점은 비활성 빈 칸, 보상은 골드·아이템 후보로 표시합니다. 기존 상품이 판매만으로 자동 리롤되지는 않습니다. 일반 방은 2명, 봇 연습은 1명+봇 5명이며 공유 풀 계산은 참가자 배열 전체를 사용합니다.

## 스킬 상태와 주기 설명

오른쪽 유닛 정보와 상세 창의 스킬 제목은 ‘스킬’입니다. ‘조건 대기’·‘전투 시작 대기’·‘효과 유지 중’ 문구와 빈 상태 줄을 제거했습니다. 실제 발동 횟수가 증가하면 해당 카드에 0.5초 동안 노란빛이 나타나고, 지속형 스킬이 활성 상태인 동안에는 초록색으로 표시합니다. 횟수를 소모한 스킬의 ✓와 재사용까지 남은 시간, 현재/최대 코스트는 유지합니다. 설명은 제목 옆 ⓘ에서 확인합니다.

기본 공격 시 코스트 5, 피격 시 코스트 3을 회복하고 스킬별 추가 회복량을 더합니다. 별도 설정이 없는 지속형 스킬은 유지 중 회복하지 않습니다. 공격 주기의 고정 ms 감소는 유닛의 실제 기본 공격 간격을 기준으로 계산한 %로 표시합니다. 피버의 실제 공격 간격 배율은 기본 능력치와 분리하며 [피버 매뉴얼](COMBAT_FEVER.md)에서 조절합니다.

## 유닛 요약과 선택 표시

파란 ★는 합성 강화 등급, 노란 ★ 숫자는 종류별 레어도입니다. 강화·레어도·가격을 같은 줄에 표시하고 가격은 1G처럼 간단히 적습니다. ‘기본 가격’, 장비 개수/최대 개수, 전장/대기석 위치와 ‘강화 장비 능력치’ 설명은 반복 표시하지 않습니다. 능력치 아이콘과 설명은 [능력치·모션 수정 매뉴얼](CHARACTER_CUSTOMIZATION_GUIDE.md)을 참고하세요.

선택한 유닛의 머리 위에는 노란 역삼각형, 해당 전장 칸과 대기석에는 노란 윤곽을 표시합니다. 준비·전투와 관전 시점에서도 현재 선택을 식별합니다. 시점 변경이나 해당 유닛이 사라지는 다음 준비에서는 선택 상태를 정리합니다.

## 플레이어 체력

플레이어 체력은 오른쪽 독립 순위표에서 확인합니다. 전장 좌우 카드는 v0.20.55에서 제거했고 정사각형 전장이 그 공간을 사용합니다. 체력은 각 대전 종료 순간 반영하며 결과 페이즈 종료를 기다리거나 중복 차감하지 않습니다.

## 상점 자동 갱신 시점

라운드 결과에서는 전투 중 보던 상품과 구매 완료 상태를 유지합니다. 결과 시간에도 남아 있는 상품을 구매하거나 5골드로 수동 리롤할 수 있습니다. 다음 라운드의 준비 단계에 진입할 때 수입·경험치 지급과 함께 상품 5개를 무료로 한 번 갱신하고 구매 완료 칸을 채웁니다. 첫 준비는 최초 입장 상품을 유지하며, 다음 준비 없이 경기가 끝나면 추가 자동 갱신이 없습니다. 변경 위치는 `shared/engine.ts`의 `prepare()`입니다.

## 유닛 능력치와 방어력

오른쪽 유닛 패널과 유닛 상세 창은 이름 대신 아이콘과 수치를 3열로 표시합니다. 순서는 체력·공격력·방어력 → 치명타 확률·치명타 피해·공격 속도 → 사거리입니다. 체력은 초록 하트, 공격력은 빨간 총알, 방어력은 파란 방패, 사거리는 흰색 양방향 화살표입니다. 치명타 확률은 금색의 일부 잘린 가시 모양 충격 문양, 치명타 피해는 같은 문양의 오른쪽 아래에 흰색 위 화살표를 더합니다. 공격 속도는 금색 스톱워치입니다. 아이콘은 `client/unit-stats.ts`의 SVG이며 모든 화면에서 같은 모양을 사용합니다.

각 칸은 최소 44px 이상의 도움말 영역입니다. PC는 마우스를 올리면, 모바일은 한 번 누르면 이름·값·의미가 툴팁으로 나타납니다. 모바일은 다시 누르거나 바깥을 눌러 닫습니다. PC 클릭으로 툴팁을 전환하지 않습니다. 수치와 이름을 접근성 레이블로 제공하며 아이콘을 별도로 읽지 않습니다.

전원 기본 치명타 확률 10%, 총 치명타 피해 150%입니다. 수치 방어력은 기존 색상 방어 속성과 별개이며 기본 공격과 공격 스킬에 실제 적용됩니다. 일반 유닛은 방어력 8~10, 루멘은 12, 아르덴은 14입니다. [실제 계산식·수치·조정 근거](COMBAT_BALANCE.md)를 확인하세요. 치명타 피해 숫자는 속성색을 유지하며 크기와 `!`로 강조합니다. 배리어 초과 피해는 기존처럼 연한 파란색 숫자와 공격 속성색 숫자로 나눠 표시합니다.


## 공격 속도

공격 속도는 두 번째 줄의 세 번째 칸입니다. 스톱워치 옆에 소수점 둘째 자리 숫자와 작은 등급 문구를 함께 표시합니다. 이름과 회/초 단위는 툴팁에서 확인합니다. 0.70 미만 매우 느림, 0.70 이상 0.90 미만 느림, 0.90 이상 1.10 미만 보통, 1.10 이상 1.30 미만 빠름, 1.30 이상 매우 빠름입니다. 표시 숫자를 기준으로 등급을 정하며 0.5~1.5로 표시를 제한하지 않습니다.

설정된 공격 주기를 실제 100ms 전투 진행 간격으로 올림한 뒤 초당 공격 횟수로 환산합니다. 기본값은 루멘 1.00·보통, 실바 1.25·빠름, 노바 0.71·느림, 아르덴 0.83·느림, 카이 1.11·빠름, 세라 0.91·보통입니다. 다른 능력치와 같은 조회 기준을 사용하므로 전투 중 내 유닛 상세는 다음 전투 기준입니다. 일시적 전투 버프의 실시간 수치를 별도 전송하지 않습니다. 짧은 화면에서는 상세 내부를 스크롤해 마지막 공격 속도 카드와 닫기 버튼에 접근할 수 있습니다.

## 전장 출전 수와 대기석

출전 수/최대 출전 수는 전체 8×8 전장의 정중앙에 반투명으로 표시하며 **전투 중에는 숨깁니다**. 숫자 영역은 클릭·드래그를 가로막지 않습니다. 전장 아래 사각형 정원 표시와 그 줄은 제거했습니다. 대기석 12칸은 빈 칸·유닛 칸 모두 정사각형입니다. PC는 너비에 맞춰 44px 이상으로, 모바일 세로는 48px, 모바일 가로·짧은 가로 PC는 44px로 표시합니다. 좁은 화면은 기존 좌우 이동으로 뒤쪽 칸을 확인합니다. 칸 안의 이미지는 비율을 유지하고 이름·강화·장착 표시를 함께 표시합니다.

수정 위치: `client/main.ts`(출전 수·조합), `client/pc-layout.ts`(전장과 대기석 배치), `client/style.css`(중앙 표시·대기석 높이)입니다.

## 참가자 순위표와 전장·대기석 관전

순위표는 화면 오른쪽의 독립된 세로 열입니다. PC는 유닛/전투 패널 오른쪽에, 모바일 세로는 전장 오른쪽에 둡니다. 모바일 가로는 상점 오른쪽 끝에 둡니다. 유닛/전투 정보의 높이를 차지하지 않습니다. 좁고 낮은 화면은 순위 목록을 세로로 밀어 마지막 참가자까지 확인합니다. PC는 이름을 마우스 호버로 확인하고 모바일은 참가자를 눌러 관전 안내에서 이름을 확인합니다.

행에는 순위·초상화·체력과 작은 체력 바를 압축 표시합니다. 전체 이름은 접근성 이름에도 포함합니다. 체력 내림차순이며 동률은 참가 순서를 유지합니다. ‘나’와 현재 대전 상대의 ‘VS’를 구분하고, 현재 보고 있는 유저는 파란 테두리로 표시합니다. 체력이 0인 유저는 아래쪽에 회색으로 남습니다. 정렬이 바뀌어도 관전 대상은 ID로 유지합니다.

유저를 누르면 그 유저의 전장 배치·출전 조합·12칸 대기석을 표시합니다. 배치는 해당 유저의 시점으로 아래쪽 4행에 놓습니다. 관전 중에는 전장 바깥 위쪽의 안내 줄에 유저 이름과 ‘내 전장으로’ 버튼이 표시됩니다. 안내는 작은 가로 화면에서도 전장 칸을 가리지 않으며 복귀 버튼은 높이 44px 이상입니다. ‘확인 전용’ 문구는 표시하지 않습니다. 유닛·대기석 유닛을 누르면 능력치·스킬·착용 장비를 확인합니다. 모바일은 상세를 바로 열고, PC는 오른쪽 정보와 초상화를 사용합니다.

PvP 준비·매칭 중에도 순위로 선택한 유저의 배치·대기석·착용 장비·출전 조합을 표시합니다. `opponentId`와 `battlePairs`는 비워 실제 매칭 상대와 순위의 VS를 전투 시작까지 숨깁니다. 순위의 참가자 이름·남은 체력은 유지합니다. PvE 혼자 연습에서는 준비 중에도 선택한 유저와 연습 상대의 현재 배치를 함께 표시하며 배치 변경을 실시간 반영합니다.

PvP는 준비 시간이 끝나거나 모두 준비 완료하면 **5초 매칭**에 들어갑니다. 이때 유닛 배치·구매·판매·장비·보상 선택을 잠그고 경험치·리롤·준비 재확인을 허용하며 상단 단계와 타이머로 남은 시간을 표시합니다. 매칭이 끝나 전투가 시작되면 대전 상대·양쪽 전투 유닛·상대 대기석·착용 장비 조회를 이어갑니다. PvE는 이 매칭 단계를 거치지 않습니다. 다음 준비에서도 참가자 배치와 대기석 조회를 계속 지원하고 대전 쌍만 다시 비웁니다. 일반 방은 2인이고, 별도 봇 연습에서는 실제 6인 순환 매칭과 세 독립 전장을 지원합니다.

전투·결과 중에는 선택한 유저가 참가한 전장의 양쪽 전투 유닛을 함께 표시하고, 선택한 유저의 방향으로 전장을 뒤집습니다. 실제 이동·공격 효과·피격·체력·스킬 상태가 계속 갱신됩니다. 전투 중 구매 또는 결과 중 판매로 보유 목록이 달라져도 전투 화면은 그 전투에 출전한 유닛을 유지하고, 대기석은 현재 보유 상태를 표시합니다. 합성은 다음 준비에서만 적용합니다. 양쪽 전투 유닛과 대기석 유닛을 눌러 상세를 확인할 수 있습니다.

관전 중 출전 조합은 선택한 유저의 조합입니다. 전투 중에는 사망 유닛을 포함한 전투 시작 조합을 사용합니다. 상점·골드·보유 장비는 항상 내 정보입니다. v0.20.49부터 **관전 중에도 내 상점 상품을 구매**할 수 있으며 내 골드를 사용해 내 대기석에 추가합니다. 준비 중에는 즉시 합성하고 전투·결과에서는 다음 준비까지 보류합니다. 관전 대상과 선택한 상대 유닛을 유지하고 진행 중인 전투는 바꾸지 않습니다. 유닛 구매는 준비 완료한 준비 단계·매칭·마감·보상 확인에서 잠기며 경험치/리롤은 매칭에도 허용합니다. 관전 중에도 내 경험치·리롤·준비 완료를 사용할 수 있으며 배치·판매·장비 변경·제작은 계속 잠급니다. ‘내 전장으로’ 또는 내 순위 행을 누르면 선택을 정리하고 원래 권한을 복원합니다. 관전은 경기 시간을 멈추지 않습니다.

새 보상 선택·최종 결과가 열릴 때는 내 전장으로 복귀합니다. 보상 창을 눈 버튼으로 숨긴 확인 모드에서는 순위표도 잠기므로 기존 유닛 상세 전용 범위를 유지합니다. 새 방·대상 퇴장 시 관전을 해제하며 새로고침 후에도 내 전장으로 시작합니다.

서버는 상대의 배치 유닛과 별도의 `bench` 목록(슬롯 포함), 보유 유닛/전투 유닛의 착용 장비만 공개합니다. 상점·골드·경험치·보관 장비·보상 선택지·합성 내부 정보는 공개하지 않습니다. 순위의 현재 상대는 체력 순서와 별개인 `opponentId`로 구분합니다.

일반 방은 사람 2명, PvP 연습은 사람 1명+서버 봇 5명입니다. 순위는 실제 참가자의 체력을 표시하며 봇 연습에서 순환 매칭·세 독립 전장·탈락 후 관전을 지원합니다. 기존 UI용 6인 사본과 실제 봇 연습 브라우저 검사를 구분합니다. 실제 사용자 6명 접속은 후속 작업입니다.

수정 위치: `client/ranking-ui.ts`(순위표·복귀 안내), `client/scouting.ts`(정렬·대전 쌍·관전 상태와 전장 투영), `client/main.ts`(조회·조작 잠금), `client/board.ts`(화면 전환 시 효과 정리), `client/unit-inspection.ts`(배치/전투 상세 구분), `shared/model.ts`·`shared/snapshot.ts`(공개 데이터), `client/style.css`입니다. `Snapshot.battlePairs`는 각 전장의 두 유저 ID를 좌표 기준 순서로 제공합니다. 선택한 전장의 유닛과 이벤트만 투영하며 목록 정렬이나 내 대전 상대와 독립적으로 조회합니다. 검사: `npm run test:combat-scouting:browser`, `npm run test:ranking:browser`, `npm test`, `npm run test:network`.

## 모바일 가로·세로 화면

모바일은 세로 방향으로 고정하지 않습니다. 기기를 돌리면 같은 모바일 모드를 유지한 채 화면 배치만 자동으로 전환합니다. 화면 아래 상태에 ‘모바일 가로 화면’ 또는 ‘모바일 세로 화면’을 표시합니다. 자동/직접 선택한 PC·모바일 설정은 회전과 독립적입니다. 회전으로 새 방에 들어가거나 관전 대상을 초기화하지 않습니다.

가로 화면은 전장·대기석을 왼쪽, 라운드·정보/전투 기록·조합·장비를 그 옆 상태 열, 상점을 오른쪽, 순위표를 맨 오른쪽에 배치합니다. 낮은 화면의 순위 목록과 정보/상세 창은 내부 스크롤을 사용합니다. 상점은 기존 경험치·골드·리롤·연승/연패·준비 완료 기능을 유지하며 상품 5개를 세로로 표시합니다. 세로 화면은 아래 상점과 오른쪽 순위표를 사용합니다. 모바일과 좁은 PC 화면은 유닛을 탭하면 상세 창을 바로 열며, 유닛을 드래그하면 배치·교환합니다.

앞으로 GUI 변경 시 PC·모바일 세로·모바일 가로를 함께 확인합니다. 기준은 프로젝트 루트의 `AGENTS.md`에 저장했습니다. 주요 가로 크기는 844×390·740×360·667×375·480×320이며 태블릿 1024×768도 검사합니다. 세로→가로→세로 회전, 터치 배치/교환, 관전/복귀, 구매/경험치/리롤, 장착, 유닛 상세·장비·정보·전투 기록과 보상 확인 범위를 검증합니다. 전용 검사: `npm run test:mobile-landscape:browser`.

수정 위치는 `client/screen-mode-ui.ts`(방향·모드), `client/pc-layout.ts`(전장 공간·상태 열 측정), `client/ranking-ui.ts`(독립 순위표), `client/style.css`의 0.20.32 구역입니다.

## 상단 방 코드

현재 방 코드는 **4자리 대문자 영문 A~F·숫자**입니다. 사용 중인 코드와 충돌하면 재추첨하며 반복 충돌은 다른 빈 코드로 대체하고 방이 종료되면 반환합니다. 참가 입력도 4자리이며 소문자는 대문자로 정규화합니다. 상단 ‘효과 줄이기’ 버튼 왼쪽에 ‘방 코드’라는 이름으로 표시합니다. 기본 상태는 코드에 blur를 적용하고 화면 읽기와 선택에서 가립니다. 옆 눈 버튼을 누르면 보이고 다시 누르면 가려집니다. 눈 버튼 오른쪽의 겹친 사각형 아이콘은 방 코드를 바로 복사합니다. 코드를 숨긴 상태에서도 복사할 수 있으며 표시/숨김 설정은 바뀌지 않습니다. 두 버튼은 44×44px입니다. 복사 성공 시 체크 아이콘과 안내를 표시하고, 실패하면 성공으로 표시하지 않습니다.

HTTPS·localhost에서는 Clipboard API를 사용하고 API를 사용할 수 없는 LAN HTTP 환경은 선택 영역을 통한 복사를 시도합니다. 반복 스냅샷에서는 사용자가 정한 표시 상태를 유지합니다. 새 방 진입·로비 복귀·새로고침 시에는 숨김으로 시작하며 복사 완료 표시도 초기화합니다. 로비에는 표시하지 않습니다. 방·연결 탭에는 연결 상태만 남습니다. 너비 400px 이하의 게임 화면은 제목을 별 아이콘으로 압축하고 360px 이하에서는 제목을 숨겨 상단 버튼을 한 줄에 유지합니다.

관련 파일은 `client/room-code-ui.ts`(표시·복사·새 방 초기화), `client/main.ts`(상단 요소·스냅샷 연결), `client/pc-layout.ts`와 `client/style.css`입니다. 검사: `npm run test:room-code:browser`.

## 보상 창 눈 버튼과 유닛 확인 모드

보상 창에서 눈 버튼을 한 번 클릭하거나 터치하면 보상 내용만 숨깁니다. 눈 버튼은 원래 위치에 계속 남으며 같은 버튼을 다시 누르면 보상 선택 화면을 표시합니다. 별도의 ‘라운드 보상 보기’ 버튼은 숨긴 동안 표시하지 않습니다. 키보드는 눈 버튼에서 Enter/Space로 전환합니다.

숨긴 동안에는 전장의 아군·공개 적 유닛과 내 대기석 유닛의 상세 정보만 확인할 수 있습니다. PC는 오른쪽 패널에서 확인하고 초상화로 상세를 엽니다. 모바일·좁은 화면은 유닛을 누르면 상세를 바로 엽니다. 능력치·스킬·착용 장비 효과는 해당 유닛 정보에 포함하며, 이 확인 모드에서는 다른 유저의 관전 대기석으로 전환하지 않으며 보관 장비는 공개하지 않습니다.

장비 목록·제작·전투 기록·추가 정보·출전 조합 설명 등 다른 메뉴는 잠깁니다. 배치·구매·리롤·경험치·장착/해제/이동·판매·준비 완료도 실행할 수 없습니다. 유닛 상세의 장비 관리·판매·대기석 이동 조작은 숨깁니다. 마우스·터치 입력을 차단하고 관련 영역에 inert를 적용해 키보드 초점도 들어가지 않게 합니다. 공통 클라이언트 요청 차단은 유지합니다.

보상 내용이 숨겨진 동안 보상 창의 모달 상태를 해제해 전장 유닛을 클릭할 수 있게 합니다. 눈 버튼의 자리는 보상 창 안에 유지합니다. 유닛 상세 모달을 열 때도 같은 버튼을 같은 화면 좌표에 표시하므로 바로 보상 선택으로 돌아올 수 있습니다. 돌아갈 때 상세 창을 닫습니다. 화면 크기가 바뀌면 보상 영역과 눈 버튼을 함께 화면 안에 다시 배치합니다.

새로고침하면 미선택 보상 창을 다시 표시합니다. 시간은 계속 진행되며 마감·전투 전환·보상 수령·새 보상·새 방·개발 복원 시 확인 모드를 정리하고 원래 조작 권한을 복원합니다. 마감 시 골드 자동 선택은 유지합니다. 보상 창의 기존 ‘닫기’는 확인 모드와 독립입니다.

관련 파일은 `client/reward-presentation.ts`(상태), `client/reward-ui.ts`(모달 전환·눈 버튼 좌표·입력/초점 제한), `client/main.ts`(조작 잠금·유닛 상세), `client/help-tooltips.ts`와 `client/style.css`입니다.

## 장비·재료의 상세·조합 팝업

왼쪽 보유 목록은 장비와 재료로 나눠 개수를 표시합니다. 별도의 재료 조합 버튼은 없습니다. 아이템을 누르면 이름·등급·효과와 관련 조합만 작은 팝업에 표시합니다. 재료는 그 재료가 들어가는 조합식과 보유/필요 수량을 표시합니다. 제작 가능한 2등급 완성 장비는 원래 조합식을 읽기 전용으로 표시하고, 조합식이 없는 장비는 ‘조합식 없음’을 표시합니다. 3~5등급 보상 장비에 2등급 제작법을 붙이지 않습니다.

재료 팝업에서 조합식을 선택한 뒤 ‘조합 제작’을 누릅니다. 조회·선택만으로 재료를 소비하지 않습니다. 클릭한 재료를 우선 사용하며 같은 종류의 조합도 서로 다른 아이템 ID 두 개가 필요합니다. 성공하면 두 재료를 소모하고 2등급 장비 한 개를 지급하며, 열려 있던 팝업을 완성 장비의 상세로 갱신합니다. 골드는 소비하지 않습니다. 재료가 부족한 조합식과 준비 완료 후·전투 등 제작 불가 단계의 버튼은 비활성화합니다. 전투 중에는 설명과 조합식을 읽을 수 있습니다.

장비 팝업의 ‘장착할 유닛 선택’을 누르면 팝업을 닫고 다음에 선택한 내 유닛에게 장착합니다. 장비를 유닛으로 직접 드래그하는 방식과 유닛 상세의 장착·해제·이동 기능도 사용할 수 있습니다. 단순히 아이템 설명을 열 때는 장착 대기 상태로 바뀌지 않습니다.

팝업은 모달 배경 없이 클릭한 아이템 근처에 최대 너비 336px로 표시합니다. 화면 가장자리에서는 위치를 조정하고 낮은 화면은 본문을 스크롤합니다. 제목·닫기·최종 버튼은 계속 접근할 수 있습니다. PC에서는 다른 보유 아이템을 바로 눌러 내용을 바꿀 수 있습니다. 닫기·바깥 누르기·Escape로 닫으며 도움말이 열려 있으면 Escape가 도움말을 먼저 닫습니다. 닫기·Escape는 원래 아이템이나 접힌 장비 버튼으로 초점을 돌립니다. 회전은 방·게임 상태를 유지합니다. 보상·관전·경기 종료·로비 이동 때 정리합니다.

수정 위치: client/craft-ui.ts(상세·조합 선택·제작 요청·완료 처리·위치), client/equipment-ui.ts(아이템 클릭·드래그·장착 대기), client/main.ts(권한·요청 연결), client/help-tooltips.ts(설명), client/style.css(배치). 아이템 정의와 6종 조합식은 shared/catalog.ts, 서버 검증은 shared/crafting.ts입니다. 유저별 프로필 사진 추가 계획은 별도 docs/PLANNED_FEATURES.md에 기록했습니다.

## 전투 기록 전용 패널

전투 기록은 공용 정보 창에서 분리했습니다. PC의 넓은 화면에서는 오른쪽 ‘유닛 / 전투’ 탭으로 전환합니다. 전투가 끝나면 기록 내용을 갱신하며, 기록 버튼과 ‘전투’ 탭에는 알림 점을 표시하지 않습니다. 전장 유닛을 직접 선택하면 유닛 탭으로 돌아옵니다. 상단 기록 버튼 또는 전투 탭으로 기록을 열고, 유닛 탭이나 Escape로 닫습니다. 키보드는 탭에 초점을 둔 뒤 좌우 화살표/Home/End로 전환할 수도 있습니다.

모바일·너비 700px 이하의 PC·높이 540px 이하 가로 화면에서는 아래에서 전용 기록 패널을 엽니다. 세로 화면의 기본 최대 높이는 화면의 80%이며 ‘확대 / 축소’로 조절합니다. 짧은 가로 화면은 화면 높이에 맞춥니다. 닫기·바깥 터치·Escape로 닫고, 원래 선택은 유지합니다. 창 크기나 화면 모드를 바꿔도 같은 기록 내용을 새 위치로 옮기므로 패널·ID가 중복되지 않습니다.

스테이지 옆에는 최근 승패를 ✓ / × / =로 표시합니다. PC는 최근 5경기, 모바일·좁은 화면은 최근 3경기까지 표시하며 누르면 해당 기록을 엽니다. 전투 결과 단계에는 전장 위에 ‘승리 · 상대 체력 −8’처럼 실제 체력 감소를 요약합니다. 다음 준비 단계에서는 사라집니다.

전투 기록은 스테이지마다 5라운드씩 묶습니다. 1~5라운드는 2-1~2-5, 6~10라운드는 3-1~3-5이며 마지막 40라운드는 9-5입니다. 메인·결과 화면도 같은 표기를 사용합니다. 상단 이동은 ‘이전 / 다음’ 두 버튼이며 ‘현재’ 버튼은 제거했습니다. 그 아래는 라운드 선택, 선택한 전투 결과와 기여도입니다. 라운드별 체력 감소 규칙은 표시 묶음과 분리해 기존 값을 유지합니다. 체력 전후·감소·생존 유닛은 맨 아래 ‘체력 · 생존 유닛’을 펼쳐 확인합니다. 시간 초과·양쪽 전멸은 결과 아래에 표시합니다. 기록이 없으면 빈 상태를 표시합니다. 경기 종료의 ‘전투 기록 보기’도 이 패널을 사용합니다.

기여도는 기본 ‘준 피해 / 아군’이며 받은 피해·회복량·보호막 방어와 상대 진영으로 전환할 수 있습니다. 선택한 항목의 내림차순으로 유닛을 정렬하며 같은 종류의 유닛도 개별 행으로 표시합니다. 막대와 수치는 실제 완료 기록을 사용하고, 양쪽 진영에 같은 최대 눈금을 적용해 전환하면서 비교할 수 있습니다. 전부 0이면 막대 길이를 0으로 표시합니다. 지난 라운드 선택·항목·진영은 새로고침 후 복원하되 패널은 자동으로 열지 않습니다.

관련 파일: `client/combat-panel.ts`는 PC 탭·모바일 패널 위치와 동작, `client/history-ui.ts`는 기록·결과 요약·필터, `client/history.ts`는 기록 선택·복원 상태, `client/contributions.ts`는 그래프 출력입니다. 게임·전투·상점 규칙은 유지합니다.

## 출전 조합

수호·정찰·비전 중 전장에 1종 이상 배치한 계열만 표시합니다. 0종인 계열은 표시하지 않고 마지막 유닛을 회수하면 해당 행을 제거합니다. 1종부터 현재 출전 종류 수를 표시하고 ‘활성’ 문구는 표시하지 않습니다. 2·4·6종 단계 중 가장 높은 효과와 상태 색을 적용하며 최종 단계 표시 디자인은 후보 비교 후 결정합니다. ‘1종 필요’처럼 부족한 수를 설명하는 문구는 표시하지 않습니다. 출전 유닛이 없으면 빈 상태를 표시합니다. PC 왼쪽 패널은 활성 효과 설명도 함께 표시합니다. v0.20.45에서 ‘효과 · 상대’/‘상대’ 펼치기와 중복 효과·상대 목록을 삭제했습니다. 상대 조합은 순위에서 해당 유저를 선택해 같은 메인 조합 창에서 확인합니다. ⓘ 도움말은 조합 발동 기준과 표시 기준을 설명합니다.

600px 이하의 짧은 가로 화면은 스테이지와 페이즈를 짧게 표시하고 남은 시간을 그 옆에 둡니다. 조합과 장비 버튼의 공간을 확보하며, 최근 결과는 전투 기록 메뉴에서 확인합니다. 스테이지와 페이즈의 전체 이름은 접근성 이름에 유지하며, 라운드 숫자는 제목과 접근성 이름에서 모두 제거했습니다.

준비 중에는 현재 배치를 보여주며 배치·대기석 회수·교환 결과가 서버에서 확인되면 바로 갱신합니다. 같은 종류 여러 개는 한 종류로 세고 대기석은 제외합니다. 전투·결과에서는 시작 시점 조합을 유지하므로 유닛 사망으로 효과 표시가 사라지지 않습니다. 제목은 준비 중 ‘출전 조합’, 전투·결과 중 ‘전투 조합’입니다.

정보 창에는 보상·수입, 연결·도움말을 유지합니다. 장비·재료·제작은 왼쪽 장비 영역, 출전 조합은 메인 화면, 전투 기록은 전용 패널에서 확인합니다.

## 필요한 때 보는 도움말

장비의 드래그·클릭 장착 방법, 조합 집계 방식, 재료 제작 방법, 보상 선택 규칙, 수입 규칙, 유닛 조작, 전투 기여도 집계 설명은 제목 옆 **ⓘ**에서 확인합니다. 보상 창의 눈 버튼과 최종 결과의 다시 플레이 안내도 툴팁으로 옮겼습니다. 장비 카드에서는 ‘드래그 장착’을 빼고 등급만 표시합니다. 장비·재료 없음, 선택한 장비의 효과, 조합별 보유/필요 수량, 능력치·확률·전투 수치와 처리 상태는 계속 표시합니다.

모바일 화면 모드는 ⓘ를 터치하면 열리고, 다시 누르거나 바깥을 누르면 닫힙니다. PC 화면 모드는 마우스를 버튼 위에 올린 동안만 열리며 벗어나면 닫힙니다. 일반 ⓘ와 연승/연패는 PC 클릭으로 고정하지 않습니다. 조합 키워드는 PC에서도 클릭·Enter/Space로 열고 다시 눌러 닫습니다. Escape는 열린 도움말을 닫습니다. Escape는 도움말을 먼저 닫으므로 원래 정보·보상 창이나 선택한 장비가 함께 닫히지 않습니다. 툴팁은 별도 모달을 열거나 초점을 가두지 않으며, 화면 가장자리 안에 위치합니다.

전체 플레이 방법은 기존 정보 창의 ‘도움말’ 탭에 있습니다. 제작법은 왼쪽의 재료를 눌러 해당 재료의 팝업에서 확인합니다. 상점·골드·경험치·리롤·준비 완료 배치는 유지합니다.

수정할 때는 `client/help-tooltips.ts`의 설명·원본 문구 매핑·제목별 버튼 등록을 확인하세요. 보상·조합 시점 등 수시로 바뀌는 문구는 원래 ID를 유지한 숨겨진 원본에서 읽습니다. 본문을 화면에 다시 표시하지 않고도 최신 안내가 툴팁에 반영됩니다. 선택 유닛 이름 옆 버튼은 `client/main.ts`, 표시 스타일은 `client/style.css`에서 관리합니다.
