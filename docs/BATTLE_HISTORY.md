# 0.11.0 전투 기록과 유닛별 기여도

전장 상단 중앙에 **전투 기록** 버튼을 표시합니다. 진행표와 상세 결과는 기본적으로 접혀 있습니다. 새 결과가 생겨도 자동으로 열리지 않습니다.

## 조작

- 전투 기록 버튼: 진행표 열기/닫기. 전체를 닫으면 상세 결과도 숨깁니다.
- 지난 라운드 버튼: 상대 이름, 승패, 양쪽 체력 전후/실제 감소량/생존 유닛 수와 유닛별 기여도 표시.
- 상세 닫기: 진행표는 유지하고 상세 결과만 숨깁니다.
- 이전/다음: 스테이지 이동. 현재 스테이지 버튼으로 경기 진행 위치로 돌아갑니다.
- 같은 경기에서 닫았다가 다시 열면 마지막으로 보던 스테이지와 선택한 결과/상세 열림 상태를 유지합니다. 상세를 따로 닫았으면 다시 열어도 상세는 닫혀 있습니다.
- 새로고침/재접속 시 선택한 기록과 스테이지는 복원하되 진행표는 기본 접힘으로 시작합니다. 새 방에서는 새 경기 상태로 초기화합니다.
- 기록 조회는 서버 조작 요청을 보내지 않으며 준비 완료/전투 중에도 사용할 수 있습니다.

## 기록 내용과 범위

서버가 전투 종료 시 한 번 기록합니다. 라운드, 라운드 승자, 종료 사유(승리/양쪽 전멸/시간 초과), 양쪽 참가자 ID/이름, 체력 전후, 실제 감소량, 실제 전투 생존 수를 저장합니다. 기록은 다음 라운드에 전투 상태가 초기화되어도 유지되며 재접속 스냅샷에 포함합니다. 골드·예상 수입·상점·대기석은 결과표에 포함하지 않습니다.

체력이 1 남았을 때 예정 피해 2로 탈락했다면 **실제 감소 1**로 표시합니다. 전투 중 합성으로 보유 목록이 바뀌어도 생존 수는 진행하던 전투 참가자로 계산합니다. 최종 경기 승자는 별도이며 과거 라운드 승자를 덮어쓰지 않습니다.

한 스테이지는 6라운드입니다. 1라운드는 2-1, 7라운드는 3-1이며, 최대 40라운드의 마지막 스테이지는 4칸입니다. 승리/패배/무승부에는 기호와 글자를 함께 표시합니다. 아직 끝나지 않은 라운드는 준비/진행/예정 표시만 하며 클릭할 수 없습니다. 디버깅 프리셋으로 건너뛴 과거 라운드는 ‘기록 없음’으로 표시합니다.

현재 경기의 기록은 서버 방 메모리에서 유지됩니다. 방 종료/삭제나 서버 재시작 이후 영구 보관하는 계정/DB 기능은 이번 범위가 아닙니다. 디버깅 저장/복원은 기록을 함께 되돌리며 새 시작 프리셋은 기록을 초기화합니다. 화면에는 이전 상태에 없는 결과를 계속 표시하지 않습니다.

## 유닛별 기여도

지난 라운드 상세 결과 아래에서 나와 상대의 출전 유닛을 각각 확인합니다. 유닛 이름·당시 강화 등급과 다음 네 값을 표시하며, 각 팀 안에서 준 피해가 큰 순서로 정렬합니다. 같은 종류의 복사본과 사망한 유닛도 각각 표시합니다. 출전하지 않은 팀에는 ‘출전 유닛 없음’을 표시합니다. 좁은 화면은 두 팀을 위아래로 배치하고 각 유닛의 네 값을 2×2로 표시합니다.

| 표시 | 집계 기준 |
| --- | --- |
| 준 피해 | 기본 공격과 스킬로 실제 감소시킨 적의 HP. 보호막 흡수분·초과 피해 제외 |
| 받은 피해 | 실제 감소한 자신의 HP. 피해 감소 효과·보호막 흡수분 제외 |
| 회복량 | 자신과 아군에게 실제 회복시킨 HP를 시전자에게 집계. 과잉 회복 제외 |
| 보호막 방어 | 자신의 보호막이 실제 흡수한 피해. 보호막 부여량과 일반 피해 감소 효과 제외 |

보호막을 제공한 시전자의 수치가 아니라 보호막으로 피해를 흡수한 유닛의 방어량입니다. 예를 들어 30 보호막으로 50 피해를 받으면 공격자 준 피해 20, 피격자 받은 피해 20·보호막 방어 30입니다. HP 5를 회복할 수 있는 대상에게 20 치유를 적용하면 시전자의 회복량은 5입니다.

서버의 전투 참가자마다 독립 누적 값을 갖습니다. 이벤트 표시 목록이 80개로 잘려도 합계는 유지됩니다. 다음 전투에는 0부터 시작하며 종료 시 당시 ID/소유자/종류/강화/네 수치를 결과에 복사합니다. 전투 중 합성·구매로 보유 목록이 바뀌어도 진행 중인 참가자와 과거 결과는 바뀌지 않습니다. 대기석은 포함하지 않습니다. 체크포인트 저장/복원은 진행 중 누적 값과 완료 결과를 함께 복원합니다. 표시는 소수 첫째 자리까지 반올림하며 서버는 원래 누적 정밀도를 유지합니다.

패널의 접힘/조회 동작은 동일합니다. 결과가 생겨도 자동으로 열리지 않으며, 상세를 닫으면 기여도도 함께 숨깁니다. 서버·클라이언트를 함께 교체해야 합니다.

## 파일과 검증

- `shared/model.ts`, `shared/engine.ts`: 기여도/결과 타입, 시작 시 초기화와 종료 시 기록.
- `shared/skills.ts`: 기본 공격·스킬 피해·치유·보호막 흡수의 실제 변화 집계.
- `shared/snapshot.ts`: 기록의 명시적 허용 목록과 깊은 복사.
- `client/history.ts`: 접힘/선택/스테이지/복원 상태.
- `client/history-ui.ts`, `client/contributions.ts`: 상단 진행표, 상세 결과, 팀별 기여도, 선택 상태 저장.
- `tests/contributions.test.ts`, `tests/history.test.ts`, `tests/history.network.test.ts`: 실제 변화/초과분 제외·치유 귀속·범위/지속 효과·기록 고정/복사·복원·표시·실제 서버 기록 검사.
- `npm run test:history:browser`: 모바일 버튼/조회/닫기/재접속/스테이지/화면 폭 검사. 별도 Playwright와 Chromium 필요. 현재 작업 환경에서는 Chromium 부재로 화면 검증 미완료.

과거 배치·장비 재현은 후속 작업입니다. 기존 경제·성장·피해·장비 수치는 변경하지 않았습니다.

## 수동 화면 확인

`npm run dev:debug` → 혼자 연습하기 → 개발 디버깅 → 일시정지 → 조합 · 6종 → 시작 상태 적용 → 다음 단계(전투) → 다음 단계(결과). 전투 기록이 자동으로 열리지 않는지, 3-1을 선택했을 때 양쪽 6명과 피해/치유/보호막 방어가 나오는지 확인합니다. 상세 닫기/전체 닫기/다시 열기와 다음 라운드/새로고침 뒤 이전 값 유지, 320px 세로·좁은 가로·데스크톱에서 잘림 없이 표시되는지도 확인합니다. 기존 docs/screenshots는 이전 버전 자료이며 이 기능의 화면 검증 자료가 아닙니다.

## 최종 결과에서 열기 (0.12.0)

최종 결과의 전투 기록 보기 버튼은 결과 창을 닫고 이 진행표/상세를 엽니다. 선택했던 기록이 있으면 유지하고 없으면 마지막 완료 전투를 선택합니다. 완료 기록이 없으면 버튼을 비활성화합니다. 경기 종료 결과 창의 자동 표시와 기록 패널의 기본 접힘은 별개입니다. 결과/로비/새 경기 흐름은 FINAL_RESULTS.md를 참고하세요.
