# 조합 단계와 유닛 상세·관전 조작 (0.20.63)

## 집계와 단계

유저 선택에 따라 **서로 다른 유닛 종류만** 셉니다. 같은 종류의 여러 유닛·다른 강화 등급·대기석은 추가 인원으로 세지 않습니다. v0.20.58에서 요청에 따라 임시 유닛 12종을 추가해 총 18종, **각 계열 6종**입니다. 이제 4·6종 효과를 실제로 달성할 수 있습니다. [전체 목록과 조합별 디버깅 방법](EXPANDED_UNITS.md).

| 조합 | 2종 | 4종 | 6종 |
|---|---|---|---|
| 수호 | 강화 기본 체력 +15% | +30% | +50% |
| 정찰 | 강화 기본 공격력 +15% | +30% | +50% |
| 비전 | 시작 보호막 +30 | +60 | +100 |

가장 높은 달성 단계의 효과만 적용합니다. 3종은 2종 단계, 5종은 4종 단계입니다. 효과는 해당 계열 유닛에게 적용하며 전투 시작 조합을 고정합니다. 사망은 이번 전투의 조합을 해제하지 않습니다. 신규 종류를 추가하면 별도 조합 엔진 수정 없이 상위 단계로 진입합니다.

메인 화면의 **‘활성’ 문구는 제거**했습니다. 유저 확인에 따라 `3/5/7`은 표시 형태의 예시로만 보고, 실제 발동 기준은 **2·4·6종으로 유지**합니다.

## 숫자로 압축한 표시

각 행은 `4 수호 2/4/6`처럼 **현재 종류 수 → 조합 이름 → 단계 기준** 순서로 표시합니다. 현재 종류 수는 이름의 바로 왼쪽이며 흰색입니다. 단계마다 별도의 칩·배지·진행 막대를 만들지 않습니다.

- **가장 높은 달성 기준 하나**만 흰색입니다. 4종과 5종이면 `4`만 흰색이고 `2`와 `6`은 어두운 회색입니다. 2~3종은 `2`, 6종 이상은 `6`만 흰색입니다. 첫 기준 미달이면 전부 회색이며 구분자 `/`도 회색을 유지합니다.
- 툴팁 제목은 `수호 4`처럼 **이름과 현재 인원**만 표시합니다. `조합` 접미사와 반복된 `2/4/6종` 줄은 없습니다. 메인 행의 단계 기준은 `2/4/6`만 표시합니다.
- 효과는 `수호 유닛의 강화 기본 체력 15%/30%/50% 증가`처럼 공통 문구를 한 번만 표시하며 증가 기호 대신 단어를 사용합니다. 메인 행의 `2/4/6`과 같은 순서이며 **현재 적용되는 값 하나**만 흰색입니다. 4~5종이면 `30%`만 흰색입니다. 실제 적용 효과와 표시가 같고 누적하지 않습니다.
- 정찰은 강화 기본 공격력 `15%/30%/50% 증가`, 비전은 시작 보호막 `30/60/100 증가`입니다. 표시 값은 각 단계의 실제 보너스에서 계산합니다.
- PC 왼쪽 조합 창과 전장 위의 좁은 PC·모바일 화면은 이름과 숫자만 한 줄로 보여 높이를 줄입니다. 480×320처럼 특히 좁은 가로 화면에서는 같은 44px 버튼 안에 `현재 수+이름`과 기준 줄을 위아래로 두며 현재 수는 이름 왼쪽을 유지합니다. 조합 행을 누르면 이름/현재 수와 같은 색 규칙의 효과만 툴팁에서 확인합니다. 집계/대기석/최상위 적용에 관한 설명 문단은 없습니다. 터치 영역은 행당 최소 44px입니다.
- 예전 숫자 칩/막대/배지 후보 대신 이 숫자 방식으로 확정했습니다. v0.20.58의 새 캐릭터도 기존 종류 집계 규칙으로 4·6종에 참여합니다.

## 조합 배경 단계

v0.20.63부터 **비활성은 원래 배경(`#162337`)과 호버 반응**을 유지하고 빛나지 않습니다. 1단계인 2~3종은 브론즈(`#503727`), 2단계인 4~5종은 실버(`#3a4a5d`), 3단계인 6종 이상은 골드(`#5b491f`)입니다. 활성 배경을 약간 밝히고 밝은 테두리와 정적인 내부/외부 발광을 더했습니다. 0종은 기존대로 행을 숨깁니다. 종류 수가 줄면 이전 단계로 돌아가고 비활성에서는 발광이 사라집니다. 전투 중 사망은 고정 조합/배경을 바꾸지 않습니다. PC·모바일·다른 유저 관전 모두 같은 규칙입니다.

퍼플(`#4d2f63`)은 **향후 4단계용**으로 준비했습니다. 현재 실제 효과는 2·4·6의 세 단계이며 네 번째 인원 기준/보너스는 추가하지 않았습니다. `TRAITS.*.tiers`에 네 번째 단계를 정의하면 달성 단계 순서로 퍼플을 자동 연결합니다. 색·밝기·발광은 `client/style.css`의 0.20.63 부분, 단계 연결은 `client/synergy-ui.ts`의 `data-synergy-grade`에서 수정합니다.

## 유닛 상세

PC 정보 패널과 모바일/PC 상세 모달의 배경은 내 유닛이면 **어두운 파랑 `#16283f`**, 다른 유저나 중립 적이면 **어두운 빨강 `#34212a`**입니다. 밝은 색 면적을 줄여 기존 어두운 게임 화면에 맞춥니다. 색은 **현재 관전 시점이 아니라 실제 로그인한 내 유저의 소유권**을 기준으로 합니다. 내/적 관계를 반복하던 눈에 보이는 문구는 제거하고 역할·계열은 유지합니다. 스크린 리더용 관계 이름은 남깁니다. 이름·도움말·강화 파란 별·레어도 노란 별의 글자도 어두운 배경에 맞춥니다.

## 관전·매칭 중 조작

다른 플레이어를 보는 중에도 **내 골드/경험치/상점으로** 경험치 구매·리롤·준비 완료를 처리합니다. 관전 대상과 선택한 유닛은 바꾸지 않습니다.

5초 매칭 중에도 경험치 구매·리롤·준비 재확인을 허용합니다. 준비 완료를 다시 눌러도 매칭 시작/종료 시각은 바뀌지 않고, 중복 확인 때문에 다른 버튼을 잠그지 않습니다. 구매한 레벨은 내 다음 전투 출전 한도를 바꾸지만 배치/추가 출전을 자동 실행하지 않습니다. 매칭 중 유닛 구매·배치·장비 변경·판매와 제작은 잠금을 유지합니다. 보상 확인 모드, 연결 복구, 골드 부족, 최대 레벨, 만료된 요청 등의 제한은 계속 적용합니다.
