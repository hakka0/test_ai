# 0.20.11 상점 옆 성장 정보

골드·리롤 → 상점 상품 → 레벨·경험치·경험치 구매 → 준비 완료 순서입니다. 기존 왼쪽 성장 패널은 제거하고 보유 장비만 남깁니다. 모바일 상단 성장 줄도 제거했습니다. 성장 컨트롤은 화면 모드와 방향이 바뀌어도 같은 위치에 있습니다.

하단 창 전체 폭은 유지하고 상품 영역을 일반 PC에서 132px, 작은 세로 화면에서 70px, 낮은 가로 화면에서 76px 줄였습니다. 작은 세로 화면은 2칸×3줄 상품, 낮은 가로 화면은 5칸 한 열로 표시합니다. 대기석은 전장 바로 아래, 출전 수는 내 배치 영역 중앙 오버레이입니다.

아래는 이전 버전 안내입니다.

# 0.20.10 상점 좌우 버튼

상점은 왼쪽 골드·리롤, 가운데 상품 5개, 오른쪽 준비 완료 순서입니다. 골드는 모든 화면 모드에서 상점 왼쪽에 있으며 상점 접기 버튼은 제거했습니다. 전장 아래에는 출전 칸 아이콘과 대기석을 유지합니다. 현재/최대 출전 수는 내 배치 영역 중앙 오버레이입니다.

모바일 상단은 레벨·경험치 정보입니다. 폭 700px 이하 상품은 3칸×2줄, 낮은 가로 화면 상품은 2칸×3줄입니다. 가로 화면의 경기 정보가 대기석을 밀어내지 않게 오른쪽 정보 영역을 따로 배치하고 길면 그 정보 영역만 스크롤합니다.

아래는 이전 버전 안내입니다.

# 0.20.9 출전 수 위치

현재/최대 출전 수를 내 배치 영역인 전장 아래쪽 4행의 중앙에 반투명 오버레이로 옮겼습니다. 클릭·터치·드래그는 아래 칸으로 통과합니다. 전장 아래 경계에는 출전 칸 아이콘과 준비 완료 버튼을 유지합니다. 레벨·경험치·골드·상점·대기석은 0.20.8의 분리 배치를 유지합니다.

아래는 이전 버전 안내입니다.

# 0.20.8 PC 화면

왼쪽에는 레벨·경험치·경험치 구매와 장비 패널, 가운데에는 전장과 출전 수·준비 완료 경계 및 바로 아래 대기석, 오른쪽에는 선택 유닛 상세를 배치합니다. 상점은 화면 하단에 독립하며 골드는 상점 오른쪽 리롤 위에 표시합니다. 상점/대기석 전환 버튼은 제거했습니다.

대기석은 12칸 한 줄입니다. 상점을 접어도 대기석은 유지되며 창 높이에 따라 전장 크기를 조정합니다. 폭 700px 이하에서는 레벨·경험치·골드를 상단 줄에 모으고 장비는 펼침 패널로 표시합니다. 높이 540px 이하 가로 화면에서는 상점을 오른쪽에 두고 성장 정보·경기 정보를 전장 오른쪽에 세로로 배치합니다.

[화면 검증](SCREEN_QA.md), [분리된 상점·대기석](DOCK_TABS.md)을 참고하세요. 아래는 이전 버전 안내입니다.

# 0.17.0 PC 화면

왼쪽 보유 장비 패널 · 가운데 전장 · 오른쪽 전투 요약을 사용합니다. 상점/대기석은 하단 고정 창에서 같은 높이로 전환합니다. 경험치 구매는 창 바깥 왼쪽 위, 준비 완료는 바깥 오른쪽 위에 독립 배치합니다. 좁은 창은 오른쪽 요약을 상단 정보 버튼으로 모으며 700px 이하에서는 장비 패널을 왼쪽에서 펼칩니다. PC 판별은 UA/수동 선택을 유지합니다.
