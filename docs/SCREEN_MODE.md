# 0.14.0 PC와 모바일 화면 모드

## 기본 판별

저장된 직접 선택이 없으면 브라우저 User-Agent 문자열로 화면 모드를 정합니다. Mobi/Android/iPhone/iPad/iPod 등의 모바일 기기 표시는 모바일, 그 외는 PC를 기본값으로 사용합니다. Android 태블릿도 모바일로 처리합니다. 브라우저 창의 가로/세로 크기, 터치 가능 여부, 화면 회전은 모드를 판별하지 않습니다.

User-Agent는 실제 기기를 보장하지 않습니다. 휴대폰의 데스크톱 사이트 모드, Mac으로 표시되는 일부 iPad/태블릿, 사용자 에이전트를 바꾼 브라우저는 PC로 판별될 수 있습니다. 이런 경우 직접 모바일을 선택하세요.

## 페이지 맨 아래 버튼

게임 화면을 아래로 스크롤하면 **화면 모드** 영역이 있습니다. PC/모바일 버튼의 강조와 ‘PC 화면 · 자동’ 또는 ‘모바일 화면 · 직접 선택’ 표시로 현재 상태를 확인합니다. 버튼은 전장 위에 고정하지 않고 본문 맨 아래에 둡니다.

- **PC / 모바일**: 해당 화면을 즉시 적용하고 이 브라우저에 저장합니다. User-Agent 기본값보다 우선합니다.
- **자동 판별로 복원**: 직접 선택을 지우고 기본 User-Agent 판별로 돌아갑니다. 이미 자동이면 비활성화합니다.
- 새로고침/로비/새 경기/재접속은 직접 선택을 유지합니다. 창 크기 변경이나 회전으로 다른 모드로 전환하지 않습니다.
- 브라우저 저장이 차단돼도 해당 페이지에서는 선택할 수 있습니다. 새로고침 뒤 저장을 유지하는 기능은 저장 허용이 필요합니다.
- 모드를 바꾸면 진행 중인 드래그/판매 확인을 취소하고 전장 크기를 다시 맞춥니다. 유닛 선택·배치·골드·시간·경기 상태를 바꾸거나 서버 조작 명령을 보내지 않습니다.

## 각 모드의 배치

PC는 중앙 전장과 오른쪽의 간단한 요약, 하단 고정 대기석·상점을 사용합니다. 상세 정보는 별도 창에서 확인합니다. 전장 기본 최대 크기는 560px입니다. 높이가 부족한 PC 창은 남은 공간을 기준으로 조절하되 최소 420px를 사용합니다(실제 폭이 그보다 좁으면 폭에 맞춤). 아주 짧은 창에서는 전장 영역을 스크롤하거나 고정 창을 접습니다. 모바일의 300px 제한과 기존 모바일 조작 바는 적용하지 않습니다.

모바일은 기본 한 열로 표시합니다. 넓은 창에서 직접 모바일을 골라도 기본 한 열(최대 680px)로 확인할 수 있습니다. 세로이며 폭 819px 이하인 화면에서는 하단 조작 바를 고정합니다. 가로이며 폭 620px 이상/높이 540px 이하일 때는 기존 짧은 가로 화면의 전장+패널 배치와 전장 최대 300px를 사용합니다. 선택 모드 안에서도 작은 카드/기록/보상 창은 실제 공간에 맞게 조절합니다.

보상 팝업/눈 버튼은 유지합니다. 모드 선택은 본인 화면만 바꾸며 서버의 전투/구매/배치 권한은 동일합니다.

## 화면 확인

0.13.3에서 Chromium의 PC/Android UA, 창 크기 변경, 수동 선택/저장/복원과 모드별 레이아웃 자동 검사를 통과했습니다. 실제 화면 6가지도 캡처하여 확인했습니다. 결과는 `SCREEN_QA.md`를 보세요. 아래 항목은 실제 PC/휴대폰에서 추가 확인할 수 있습니다.

- Windows/macOS/Linux PC에서 자동 PC, Android/iPhone에서 자동 모바일인지 확인합니다.
- PC의 1440×1000/844×390/390×844 창에서 모드가 바뀌지 않고, 짧은 창의 300px 제한/세로 고정 조작 바가 적용되지 않는지 확인합니다.
- 모바일 선택 후 한 열/세로 고정 조작 바/짧은 가로 배치, PC 선택 후 전장/요약/하단 고정 창 배치를 확인합니다.
- 페이지 맨 아래 버튼의 겹침·현재 강조·키보드 조작, 선택 후 새로고침/재접속/로비/새 경기 유지, 자동 복원을 확인합니다.
- 보상 팝업 닫기/눈 버튼, 드래그 교환과 선택 유닛 상세/기록/최종 결과를 모드 전환 전후 확인합니다.

`npm run build` → `npm run setup:browser` → `npm run test:screen-mode:browser`로 실행합니다. 임시 서버 포트는 2597이며 브라우저 경로는 `CHROME_PATH`로 지정할 수 있습니다. 검증 결과는 `VALIDATION.md`를 보세요.
