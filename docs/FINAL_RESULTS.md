# 0.12.0 최종 결과 화면

## 화면과 조작

라운드 정산이 끝나고 서버가 경기를 종료하면 최종 결과 화면이 한 번 열립니다. 최종 승리/패배/무승부, 종료 사유, 도달 스테이지, 완료한 전투 수와 양쪽 이름·남은 체력·라운드 승수를 표시합니다. 준비/전투/라운드 결과 단계에는 이 화면이 열리지 않습니다.

- **닫기 / Escape**: 화면만 닫습니다. 경기와 기록은 유지합니다. 반복 스냅샷이 와도 다시 열리지 않습니다.
- **최종 결과 보기**: 전장 상단에 남은 요약에서 결과 화면을 다시 엽니다.
- **전투 기록 보기**: 결과 화면을 닫고 기존 진행표와 상세/기여도를 엽니다. 이전 선택이 있으면 그 기록을, 없으면 마지막 완료 전투를 선택합니다. 조회만으로 서버 상태를 변경하지 않습니다.
- 완료 전투가 없으면 **완료된 전투 기록 없음**으로 조회 버튼을 비활성화합니다. 진행 도중 상대가 떠난 경우 미완료 전투를 완료 기록으로 만들어내지 않습니다.
- **다시 플레이**: 연습에서는 새 연습 경기를 시작합니다. 친구 대전에서는 **다시 플레이 · 새 방**으로 새 대전 방을 만들고 상대 입장을 기다립니다. 새 방 코드를 친구에게 알려주세요.
- **로비로 돌아가기**: 기존 방을 떠나고 닉네임을 유지한 채 같은 페이지의 로비로 돌아갑니다. 로비의 연습/방 만들기/참가 버튼을 다시 사용할 수 있습니다.

새 경기를 시작하거나 로비로 돌아가면 이전 전장/선택/드래그/판매 확인/제작 선택/조회 상태를 초기화하고 재접속 토큰을 지웁니다. 중복 이동 입력은 처리 중에 막습니다. 새 접속에 실패하면 로비에 오류를 표시하고 시작 버튼을 다시 활성화합니다. 같은 페이지에서 닉네임을 유지하며, 새로고침 이후 닉네임을 따로 영구 저장하는 기능은 이번 범위가 아닙니다.

결과가 열린 동안에는 배경 조작이 차단되며 제목으로 포커스를 이동합니다. 닫기/Escape 후에는 최종 결과 보기 버튼으로, 기록 보기 후에는 선택한 라운드 버튼으로 이동합니다. 좁은 화면에서는 양쪽 체력 카드와 이동 버튼을 세로로 배치하고 짧은 가로 화면은 결과 창 안에서 스크롤합니다. 경기 종료 이후 모바일 고정 배치 조작 패널은 숨깁니다.

## 최종 판정

| 종료 사유 | 기존 판정과 표시 |
| --- | --- |
| 체력 소진 | 기존 체력 판정. 양쪽 체력이 0이면 최종 무승부 |
| 최대 40라운드 | 남은 체력 우선, 동률이면 라운드 승수, 모두 같으면 무승부 |
| 연결 종료 | 명시적으로 방을 떠나거나 기존 60초 재접속 유예가 끝나면 상대 승리 |

최종 승패는 서버의 경기 승자를 사용하며 마지막 전투 승패로 추정하지 않습니다. 체력/승수/경제/경기 길이 수치는 변경하지 않았습니다. 도달 스테이지는 경기 종료 당시 라운드이며 완료 전투 수는 실제 완료 기록 개수입니다. 예를 들어 2-3 준비 중 연결 종료라면 도달 2-3, 완료 전투 2회로 표시합니다. 개발 프리셋으로 라운드를 건너뛰어도 완료 수를 부풀리지 않습니다.

경기 종료 후 연결이 잠깐 끊겨도 재접속하여 같은 결과와 기록을 볼 수 있습니다. 새로고침으로 복원된 종료 경기에는 결과 화면을 한 번 엽니다. 개발 체크포인트 복원은 종료 사유/승자/기록을 함께 복원하며 새로운 세대로 화면 상태를 갱신합니다. 다른 준비/전투 상태로 돌아가면 결과 화면을 숨깁니다. 프리셋/새 방은 종료 사유와 결과 상태를 초기화합니다.

친구 대전의 다시 플레이는 양측 동의 재경기 기능이 아닌 새 방 만들기입니다. 기존 방을 동시에 초기화하거나 친구를 자동 이동시키지 않습니다. 결과와 전투 기록은 현재 서버 방 메모리에 보관하며 로비/새 경기 이동 후 이전 결과를 다시 불러오는 계정별 저장 기능은 없습니다.

## 구현과 검증

- `shared/model.ts`, `shared/engine.ts`, `server/GameRoom.ts`, `shared/snapshot.ts`: 서버 종료 사유와 연습/대전 모드 공개. 기존 승자 판정 유지.
- `client/results.ts`: 최종 결과의 표시 값과 한 번 열기 상태.
- `client/results-ui.ts`, `client/main.ts`, `client/history-ui.ts`, `client/style.css`: 결과 창/요약/기록 조회/새 경기/로비 연결과 반응형 표시.
- `client/net.ts`: 이전 세대의 메시지/종료/늦은 재접속/복원 응답이 새 방·토큰·시간 상태를 덮어쓰지 않도록 처리. 명시적 떠나기 시 상태 초기화.
- `tests/results.test.ts`, `tests/connection.test.ts`: 승패 관점/종료 시점/40라운드/체력 소진/중복 열림/복원/기록/새 경기 모드와 접속 경합 검사.
- `tests/results.network.test.ts`: 실제 서버와 실제 Connection으로 끝까지 진행한 연습 경기·최종 재접속/저장 복원·새 연습 경기·로비 후 대전 방 만들기, 2인 연결 종료 판정·새 방에서 친구와 재시작.
- `npm run test:results:browser`: 별도 Playwright와 Chromium 필요. 결과 열림/닫기/다시 열기/안전한 이름 표시/기록과 기여도/포커스/화면 폭/다시 플레이/로비/새로고침 후 새 시작 검사. 현재 환경은 Chromium이 없어 렌더링과 실기기 확인 미완료.

## 수동 확인

1. `npm ci`, `npm run dev:debug`로 실행하고 혼자 연습하기를 선택합니다.
2. 개발 디버깅에서 일시정지 후 다음 단계를 반복하여 경기 종료까지 진행합니다. 도달 스테이지·완료 전투·체력·승수가 실제 경기와 맞는지 확인합니다.
3. 닫기/Escape 후 자동 재열림이 없는지 확인하고 최종 결과 보기 → 전투 기록 보기로 마지막 상세/기여도를 확인합니다. 기존에 선택한 기록을 다시 열어도 선택이 유지되는지 확인합니다.
4. 다시 플레이를 눌러 1라운드/100체력/0승/빈 기록의 새 연습 경기와 새 방 코드가 나오는지 확인합니다. 로비로 돌아가 닉네임이 유지되고 다시 시작할 수 있는지도 확인합니다.
5. PC 창 두 개 또는 PC·모바일에서 친구 대전을 시작합니다. 한쪽이 로비로 돌아가면 상대에게 연결 종료 사유의 최종 승리가 표시되고 미완료 전투는 기록에 추가되지 않는지 확인합니다. 다시 플레이 · 새 방으로 만든 코드를 친구가 입력하면 새 대전을 시작해야 합니다.
6. 320px 세로, 좁은 가로, 데스크톱에서 결과 카드/버튼의 잘림과 스크롤을 확인합니다. 새로고침/재접속과 개발 저장/복원도 확인합니다.

서버·클라이언트를 함께 교체하세요. 동봉 dist는 0.12.0이며 기존 docs/screenshots는 이전 버전 자료입니다.
