# 0.20.22 준비 완료 위 연승·연패 헤더

오른쪽 준비 완료 칸의 위에 골드 헤더와 같은 높이로 연속 기록을 표시합니다. 표시 헤더는 버튼과 분리되어 있으며 눌러도 준비가 실행되지 않습니다. 준비 완료는 그 아래 영역 전체를 채웁니다.

| 현재 기록 | 아이콘·배경·표시 예시 |
| --- | --- |
| 연승 | 불 아이콘, 빨간 배경, 2연승 |
| 연패 | 물방울 아이콘, 파란 배경, 2연패 |
| 시작 전·무승부로 초기화 | 중립 배경, 기록 없음 |

서버 snapshot의 내 플레이어 `streak`와 `streakCount`를 그대로 표시합니다. 첫 승리·패배부터 횟수를 표시하고 반대 결과로 바뀌면 1부터 다시 시작합니다. 화면 모드 전환·재접속에도 서버 기록을 유지합니다. 상태가 같으면 헤더 내용을 다시 만들지 않으며 스크린리더에는 기록 변화를 알립니다.

화면 예시: [PC 연승](screenshots/shop-streak-header/pc-dock-win.png), [모바일 연승](screenshots/shop-streak-header/mobile-dock-win.png), [모바일 연패](screenshots/shop-streak-header/mobile-dock-loss.png). 재검사: `npm run test:separated-layout:browser`.

아래는 이전 버전 안내입니다.

# 0.20.21 내부 공용 골드 헤더와 전체 칸 버튼

| 위치 | 표시와 동작 |
| --- | --- |
| 왼쪽 두 칸의 공용 헤더 | 보유 골드 문구, 동전 아이콘, 현재 골드. 클릭 동작 없음 |
| 헤더 아래 왼쪽 칸 | 레벨·경험치·구매 비용을 담은 경험치 버튼 |
| 헤더 아래 오른쪽 칸 | 리롤 아이콘·문구·5골드 비용을 담은 리롤 버튼 |
| 가운데 | 유닛 상품 5개 |
| 맨 오른쪽 칸 전체 | 준비 완료 버튼 |

경험치·리롤은 공용 헤더 아래의 각 칸을 전체 너비와 높이로 채웁니다. 준비 완료는 상점 오른쪽 칸의 전체 너비와 높이를 사용합니다. 버튼 중앙뿐 아니라 위·아래·양옆의 빈 공간도 누를 수 있으며 기존 네이티브 버튼을 그대로 사용합니다. 모드 전환 시 골드와 버튼의 DOM 요소는 하나씩 유지합니다.

헤더를 포함한 왼쪽 영역의 총 가로 폭은 이전 버전과 같습니다. 경험치 게이지는 헤더 아래에서 창의 왼쪽 가장자리에 붙어 아래에서 위로 채워집니다. 경험치 4골드/4경험치, 리롤 5골드, 골드 부족·최대 레벨·준비 상태에 따른 기존 조건을 유지합니다.

화면 예시: [PC](screenshots/shop-gold-header/pc-dock.png), [모바일](screenshots/shop-gold-header/mobile-dock.png). 재검사: `npm run test:separated-layout:browser`.

| 왼쪽부터 | 표시와 동작 |
| --- | --- |

| 맨 오른쪽 | 준비 완료 버튼 |

세로 경험치 게이지는 통합 버튼의 전체 높이를 따라 상점 창 왼쪽 가장자리에 붙습니다. 아래에서 위로 차며, 게이지 자체를 눌러도 구매합니다. 레벨과 경험치 수치, 비용, 빈 공간도 같은 네이티브 버튼에 포함되어 마우스·터치·키보드로 조작합니다. 기존 별도 경험치 버튼은 없습니다.

경험치 구매는 4골드/4경험치이며 기존 서버 구매 조건을 그대로 사용합니다. 골드 부족 시에도 현재 레벨과 경험치를 흐리게 하지 않습니다. 최대 레벨에서는 게이지가 가득 차고 최대 레벨을 표시하며 구매를 막습니다. PC·모바일 모드 전환에서도 같은 버튼을 유지합니다.

화면 예시: [PC](screenshots/shop-growth-button/pc-dock.png), [모바일](screenshots/shop-growth-button/mobile-dock.png). 재검사: `npm run test:separated-layout:browser`.

# 0.20.8 분리된 상점·대기석

상점/대기석 탭과 저장된 탭 선택을 제거했습니다. 대기석은 전장 바로 아래 상시 표시하고 상점은 별도 고정 창으로 표시합니다. 상품 이미지 전체가 구매 버튼이며 구매한 유닛을 대기석에서 전장으로 즉시 옮길 수 있습니다.

상점 접기/펼치기는 상품·리롤 영역에만 적용합니다. 대기석과 보유 골드는 계속 표시합니다. PC의 성장 정보는 왼쪽 장비 위, 모바일의 성장·골드 정보는 상단, 출전 수·준비 완료는 전장 아래 경계에 있습니다. 작은 가로 화면에서는 상점이 오른쪽에 표시됩니다.

# 0.17.0 하단 창과 분리된 조작 버튼

상점/대기석은 같은 높이의 내용 영역을 사용합니다. 버튼으로 전환해도 하단 고정 창과 전장의 크기가 바뀌지 않습니다. 보유 장비는 하단 탭에서 분리해 왼쪽 별도 패널에 둡니다.

| 위치 | 기능 |
|---|---|
| 창 바깥 왼쪽 위 | 경험치 +4 · 4 G 구매 |
| 창 바깥 오른쪽 위 | 준비 완료 |
| 창 안의 공통 줄 | 레벨·출전 수·골드·경험치·상점/대기석 전환·접기 |
| 상점 | 유닛 5칸 구매, 리롤 |
| 대기석 | 유닛 12칸 선택·배치·자리 교환 |
| 전장 왼쪽 별도 패널 | 보관 장비/재료, 직접 드래그 장착, 재료 조합 연결 |

경험치/준비 버튼은 내용 영역과 최소 9px 간격을 두고 위로 돌출합니다. 48px 높이의 터치 영역을 사용하며 서로 반대 끝에 둡니다. 대기석에서도 경험치를 구매할 수 있습니다. 접기를 눌러도 두 버튼은 유지됩니다. 드래그를 버튼 위에서 끝낸 호환 클릭으로 준비/경험치/리롤을 실행하지 않습니다.

내용 영역은 96px이며 공통 줄·테두리·안전 영역을 더한 실제 창 높이는 화면 모드/폭에 따라 달라집니다. 동일한 창 크기에서는 두 탭의 높이가 같습니다. 아주 낮은 창은 전장 내부 스크롤 또는 접기로 확인합니다. 버튼이 돌출한 58px도 전장 공간 계산에 포함합니다. PC의 넓은 창은 전장 560px를 유지합니다.

PC에서는 장비 패널, 전장, 전투 요약 순으로 배치합니다. 창이 좁으면 전투 요약 버튼을 상단 정보 창으로 모으며, 폭 700px 이하 PC 창과 모바일에서는 왼쪽 장비 패널을 접어 전장 폭을 확보합니다. 화면 폭 변경은 PC/모바일 판별 자체를 바꾸지 않습니다. UA 기본값과 하단 수동 선택은 기존대로 유지합니다. 모드 선택은 분리된 게임 버튼과 겹치지 않도록 페이지 아래에 두며 스크롤해서 접근합니다.

탭 선택은 브라우저에 저장하고 새로고침/모드 변경 뒤 유지합니다. 과거의 보유 장비 탭 선택은 상점 탭으로 복원합니다. 키보드 좌우/Home/End 전환을 지원합니다. 로비에서는 고정 창과 장비 패널 모두 비활성화됩니다.
