TypeScript/Vite 빌드, 규칙·입력 테스트 192개, 실제 서버 테스트 12개를 통과했습니다. 결과 단계 진입 시 양쪽 상점의 상품 5개를 비용 없이 한 번 갱신합니다. 구매 완료 칸 보충, 새로운 상품 ID와 요청 버전, 이전 구매 요청 거부, 결과 단계 새 상품 구매, 반복 tick 및 다음 준비 단계에서 중복 갱신 방지를 검사했습니다. 시간 초과 무승부와 최종 라운드 종료도 포함합니다. 수동 리롤은 5골드입니다.

실제 Colyseus 서버에서도 결과 snapshot에 갱신된 상품이 전달되고, 오래된 요청이 거부되며, 새 상품 구매와 다음 준비 단계까지의 상태 유지가 동작함을 확인했습니다. 자동 갱신과 함께 난수 추첨이 추가되어 시간 진행 동등성 검사에는 동일한 난수 입력을 적용했습니다.

화면 배치는 0.20.6과 동일합니다. 이번에 새 브라우저 화면 검사는 실행하지 않았습니다. 상점·대기석 분리와 정보 위치는 이번 수정본에 포함하지 않습니다.
