# 치명타를 포함한 피해 계산식 3안

조사일: 2026-10-18. **후속 선택: 2안(길드워2)을 v0.20.38에 적용했습니다.** 전원 기본 치명타 확률 10%, 총 피해 150%입니다. [실제 적용식·유닛 수치·검증](COMBAT_BALANCE.md). 아래 추천도와 1안의 프로젝트용 예시는 선택 전 비교 기록이며 실제 적용식과 구분합니다.

## 공통 표기

- `P`: 공격력·스킬/무기 계수 등을 반영한 방어·치명타 적용 전 피해.
- `D`: 대상 방어력. `p`: 치명타 확률(25%이면 0.25).
- `M`: 치명타의 총 배율. 이 프로젝트에서는 **치명타 피해 150% = 1.5배**로 표기하는 안을 추천합니다.
- `C`: 한 번의 타격에 적용하는 배율. 치명타 발생 시 `M`, 일반 타격은 1입니다. 치명타 여부는 `p`로 판정합니다.

원작의 세부 상성·회피·고정 피해·치명타 불가 스킬·반올림 등은 아래 핵심식에서 생략했습니다. 게임별 방어력 수치 척도는 서로 다릅니다.

## 1. 에픽세븐 — 고정 상수의 비율 감소 + 치명타

```text
타격 피해 = P × 300 / (300 + D) × C
```

공개 계산기의 `defensivePower()`에서 방어력 계수 `1 / (D/300 + 1)`을 사용하고, `getDamage()`에서는 일반 피해에 치명타 배율을 곱합니다. `P` 안에는 원작의 공격력·스킬별 rate/pow·공통 상수 1.871 등 공격 측 계수가 들어갑니다. 이 식은 그 구현의 기본 구조를 비교용으로 정리한 것이며 Smilegate 공식 수식 발표로 소개하는 것은 아닙니다.

장점: 방어력과 치명타 확률·배율을 독립적으로 조정하기 쉽습니다. 방어력 0을 자연스럽게 처리하고 같은 방어력은 연사·단발 피해를 같은 비율로 줄입니다(반올림 전).

프로젝트 추천도: 가장 높음. 상수 300은 원작 수치 척도이므로 이 프로젝트의 작은 방어력 수치에는 100 등 별도 상수를 설계할 수 있습니다. 이전 추천식과 같은 계열이며 치명타를 추가해도 구조를 바꿀 필요가 없습니다.

출처: [Maphe 공개 계산기 소스](https://github.com/maphe/maphe.github.io/blob/master/e7-damage-calc/calculator.js), [후속 계산기 프로젝트](https://github.com/tyopoyt/epic7-damage-calc).

## 2. 길드워2 — 무기·공격력·스킬 계수 / 방어력 + 치명타

```text
타격 피해 = 무기 위력 × Power × 스킬 계수 / Armor × C
```

직접 피해를 기준으로 합니다. 원작은 기본 치명타 총 피해가 150%이며 Ferocity로 배율을 더합니다. 여기서는 표시된 최종 배율을 `M`으로 통일했습니다.

장점: 향후 총기 위력·캐릭터 공격력·스킬 계수를 나눠 설계할 때 참고하기 좋습니다. 방어력이 두 배면 직접 피해가 절반이 됩니다. 다만 방어력 0을 쓰려면 별도 기본 방어값 또는 분모 하한이 필요합니다. 원작의 Armor는 장비 Defense와 Toughness의 합입니다.

프로젝트 추천도: 총기 종류·장비 수치가 많아지는 단계의 확장안. 현재는 양의 기본 방어력과 성장 폭부터 새로 정해야 하므로 1안보다 조정 항목이 많습니다.

출처: [GW2 공식 위키의 직접 피해식](https://wiki.guildwars2.com/wiki/Damage_calculation), [ArenaNet의 치명타 피해 표기 설명](https://www.guildwars2.com/en-gb/news/learn-about-critical-damage-changes/).

## 3. 원신 — 레벨 기반 방어 계수 + 피해 보너스·저항·치명타

```text
타격 피해 = P × 방어 계수 × 저항 계수 × 피해 보너스 계수 × C

방어력 감소·무시가 없을 때:
방어 계수 = (공격자 레벨 + 100)
          / [(공격자 레벨 + 100) + (대상 레벨 + 100)]
```

원작은 방어력 감소와 방어 무시도 방어 계수에 반영합니다. 일반 직접 피해를 비교한 것으로, 별도 식을 사용하는 원소 반응 등은 제외합니다. 원신의 치명타 피해 표기는 추가 피해율이므로 +50%는 총 1.5배이며, 위의 `C`는 총 배율로 정규화했습니다.

장점: 레벨 차이, 스킬 피해 보너스, 방어력 감소/관통 등을 단계적으로 확장하기 좋습니다. 단점: 단순한 유닛 방어력 수치 외에 전투 레벨과 별도 저항 계수까지 설계해야 합니다. 이 프로젝트의 상점/출전 한도 레벨을 캐릭터 전투 레벨로 바로 대입하지 않습니다.

프로젝트 추천도: 캐릭터 육성·레벨 차이와 다수의 전투 옵션을 도입할 때 적합합니다. 현재의 자동 전투에는 1안보다 복잡합니다.

출처: [HoYoWiki 피해 계산식](https://wiki.hoyolab.com/pc/genshin/entry/5654).

## 선택 전 추천 기록 — 1안을 수치 규모에 맞춰 조정 (미채용)

```text
기본 피해 = 공격력 × 스킬/무기 계수
방어 후 피해 = 기본 피해 × 100 / (100 + max(0, 방어력))
타격 피해 = 방어 후 피해 × (치명타 발생 시 치명타 피해% / 100, 일반 타격 시 1)
```

상수 100은 원작 그대로의 값이 아닌 이 프로젝트용 제안입니다. 치명타 피해는 기본 150% 등으로 시작한 뒤 캐릭터·장비별로 조정할 수 있습니다. 기본 확률과 유닛별 수치는 아직 미정입니다.

치명타 확률은 타격 발생 여부를 결정하는 값입니다. 밸런스 비교용 평균 피해는 다음처럼 별도로 계산합니다.

```text
평균 타격 피해 = 일반 타격 피해 × [1 + p × (M - 1)]
```

예: 공격력 100, 스킬 계수 1, 방어력 50, 치명타 확률 25%, 치명타 피해 150%라면 반올림 전 일반 타격은 약 66.7, 치명타는 100, 평균 타격은 75입니다. 이 평균은 배리어·체력 상한/오버킬·치명타 연계 발동 등을 제외한 기대값이며 실제 한 번의 타격값으로 사용하지 않습니다.

동일한 치명타 기대값이어도 연사 무기는 다수의 판정으로 결과가 평균에 가까워지고, 단발 무기는 소수 판정으로 전투별 편차가 커집니다. 공격 주기까지 함께 비교해야 합니다. 치명타 배율은 배리어/체력으로 나누기 전에 한 번 적용하고, 계산된 피해를 배리어 흡수와 체력 초과분으로 분배하는 안을 추천합니다.
