# 0.16.0 하단 고정 창

PC와 모바일 모두 하단에 고정된 창을 사용합니다. 페이지를 스크롤해도 유지되며, 전투 중 자동으로 숨기지 않습니다.

| 탭 | 기능 |
|---|---|
| 상점 | 다섯 유닛 구매, 5 G 리롤, 경험치 구매 |
| 대기석 | 12칸 선택, 전장과 자리 교환, 빈 칸 배치 |
| 보유 장비 | 미장착 장비와 조합 재료 확인, 설명 팝업, 장비·제작 관리 |

레벨·출전 수·보유 골드·경험치와 준비 완료는 모든 탭에서 유지합니다. 탭은 한 번에 하나만 보입니다. **접기**를 누르면 내용 영역만 숨기며, **펼치기** 또는 탭을 누르면 복원합니다. 탭 선택은 브라우저에 저장하며 모드 변경과 새로고침 후에도 유지합니다. 저장이 차단된 경우 현재 페이지에서 전환할 수 있습니다. 키보드로 탭에 초점을 맞추고 좌우 화살표/Home/End를 사용해 전환할 수 있습니다.

유닛을 선택하면 전장 아래에 이름·상세·해제가 나타납니다. 상세 팝업에서 착용 장비와 능력치를 확인하고 장비 관리·대기석 복귀·판매를 조작합니다. 하단 보유 장비는 보관 중인 아이템 목록이며 착용 장비는 유닛 상세에서 확인합니다. 재료 조합·장비 이동/해제는 **장비 · 제작 관리**에서 가능합니다. 전투 중에는 아이템 조회가 가능하며 변경은 기존 서버 규칙에 따라 막힙니다.

모바일 대기석은 좌우 버튼으로 끝의 칸까지 접근합니다. 카드 위 드래그는 유닛 배치에 사용하므로 목록 이동은 화살표를 사용하세요. 빈 아군 칸이나 다른 내 유닛에 드롭하면 배치/교환합니다. 선택이 없던 상태에서 드래그를 시작할 때는 선택 안내가 도중에 나타나 전장 크기를 바꾸지 않도록 유지합니다.

고정 창과 전장 주변 정보의 실제 높이를 측정해 공간을 확보합니다. PC의 넓은 창은 560px 전장을 유지합니다. 모바일은 최대 480px, 실제 폭에 맞춥니다. 매우 낮은 가로 창에서는 전장 또는 고정 창 내부 스크롤과 접기가 필요합니다. 화면 모드는 User-Agent 기본 판별과 하단 PC/모바일 수동 선택을 유지합니다.

0.15.0을 Chromium에서 재확인했을 때 PC 고정 창은 표시되었습니다. 사용자가 보고한 미표시 원인은 재현되지 않았으며 특정 원인으로 단정하지 않습니다. 0.16.0은 고정 창 기본 표시를 공통화하고, 실제 실행 버전 표시와 시작 전 자동 빌드를 추가했습니다. 새 수정본을 실행하면 페이지 하단에 **v0.16.0**이 표시됩니다.
