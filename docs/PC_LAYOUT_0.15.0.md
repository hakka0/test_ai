# PC 화면 · 0.14.0 배치 유지 / 0.15.0 공통 조작 구조

## 상시 표시

중앙 전장 위에 스테이지·단계·양측 이름/체력·남은 시간·전투 기록 버튼을 모았습니다. 오른쪽에는 현재 전투/준비 안내, 계열별 출전 종류 수와 추가 정보 버튼을 둡니다. 조합을 클릭하면 구성원과 효과 설명을 확인합니다.

하단 고정 창에는 대기석 12칸과 상점 5칸이 함께 표시됩니다. 보통 PC 폭에서는 두 영역을 좌우에 배치하며 대기석은 한 줄입니다. 950px 이하에서는 대기석을 두 줄, 700px 이하에서는 두 영역을 위아래로 배치합니다. 상점 전환 버튼은 PC에서 사용하지 않습니다.

조작 줄에는 레벨·출전 수·골드·경험치, 선택 유닛, 상세·장비·대기석 복귀·준비 완료·리롤·경험치 구매가 있습니다. 대기석 카드에는 그림·이름·강화 별·장착 장비 개수를, 상점에는 그림·이름·가격을 우선 표시합니다. 유닛 상세에는 기존 능력치/계열/스킬/장비/판매 확인을 유지합니다.

하단 **접기 ▾**는 대기석/상점 영역만 접습니다. 다시 **대기석 · 상점 ▴**로 펼칩니다. 기본은 펼침, 선택은 현재 페이지에서 유지하며 전투 시작 때 자동으로 접지 않습니다. 전투 중 구매·리롤은 허용하고 배치·교환·장비·판매·경험치 구매 제한은 기존 규칙대로 적용합니다.

## 필요할 때 확인

- **전투 기록**: 지난 라운드·스테이지·승패·실제 체력 감소·양측 기여도. 조회 상태 유지와 기록 누적/재접속은 기존 기능입니다.
- **출전 조합**: 구성원·효과·상대 공개 조합.
- **아이템 · 재료 조합**: 인벤토리·장착/이동/해제·재료 선택·제작법.
- **보상 · 수입**: 보상 수령 내역·등급 확률·지난 라운드 수입.
- **방 · 연결 정보**, **플레이 방법**, 연습 경기의 **개발 도구**.

닫기/Escape/창 바깥 클릭으로 닫습니다. 정보 탭을 바꾼 뒤 닫아도 처음 연 버튼으로 키보드 초점이 돌아갑니다. 라운드 보상/최종 결과/유닛 상세가 열리면 추가 정보 창을 닫아 두 창이 겹치지 않게 합니다. 최종 결과의 기록 보기도 PC 정보 창에 연결합니다.

## 전장 크기와 공간

하단 창의 실제 높이를 측정해 본문 아래 공간과 전장 영역 높이에 반영합니다. 고정 창이 전장 위에 겹치지 않으며 페이지를 스크롤해도 유지됩니다. 넓고 충분히 높은 PC 창에서는 560px 전장을 유지합니다.

높이 850px 이하에서는 상단 정보·고정 창을 제외한 공간에 맞추되 최소 420px를 사용합니다. 실제 가로 공간이 더 작으면 폭에 맞춥니다. 아주 짧은 창에서는 최소 크기를 유지하므로 전장 영역 내부를 스크롤해야 합니다. 고정 창도 높이 상한/내부 스크롤이 있으며 접기로 전장 공간을 더 확보할 수 있습니다.

## 모바일 및 서버

User-Agent로 기본 모드를 정하고 본문 맨 아래 PC/모바일/자동 복원 선택을 유지합니다. PC와 모바일이 같은 컨트롤과 정보 창을 사용하며 각 모드의 CSS로 배치합니다. 컨트롤이나 ID를 복제하지 않습니다. 0.15.0 모바일 고정 창은 [MOBILE_LAYOUT.md](MOBILE_LAYOUT.md)를 참고하세요.

server/shared 21개 파일은 0.14.0과 동일합니다. 경제·전투·성장·보상·교환 권한을 바꾸지 않았습니다. 로비에서는 고정 창을 포함한 게임 본문이 비활성화됩니다.

## 실제 측정

초기 유닛 3명(대기석 2명)을 둔 준비 화면의 측정입니다. 카드 내용과 선택·보상 상태에 따라 고정 창 높이는 달라질 수 있으며 그때마다 다시 측정합니다.

| 창 크기 | 전장 폭·높이 | 하단 창 높이 | 전장 전체 표시 |
|---|---|---|---|
| 1440×1000 | 560px | 162px | 확인 |
| 1920×1080 | 560px | 162px | 확인 |
| 1366×768 | 460px | 162px | 확인 |
| 1024×768 | 461px | 161px | 확인 |
| 844×390 | 420px | 234px | 내부 스크롤 필요 |
