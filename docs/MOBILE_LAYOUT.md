# 0.17.0 모바일 화면

상점/대기석은 같은 높이의 하단 창에서 전환합니다. 창 바깥 왼쪽 위의 경험치 구매, 오른쪽 위의 준비 완료는 두 탭과 접힌 상태에서 모두 사용합니다. 장비는 전장 왼쪽 버튼으로 별도 패널을 펼쳐 확인합니다. 장비를 전장/대기석의 내 유닛에 드래그하면 대상 이름·장착 여부를 표시하고 드롭 시 장착합니다. 전장 폭을 줄이지 않으며 드래그 중 패널을 흐리게 해서 유닛 타게팅을 통과시킵니다.

[하단 창](DOCK_TABS.md), [장비 조작](EQUIPMENT_DRAG.md), [검증](SCREEN_QA.md)을 참고하세요. 낮은 가로 창은 하단 접기/패널·전장 내부 스크롤을 사용합니다. 이전 안내는 `MOBILE_LAYOUT_0.16.0.md`에 보존했습니다.
