# 조합 디버깅용 18종 유닛 (0.20.59)

기존 6종에 **12종을 추가해 총 18종**으로 늘렸습니다. 수호·정찰·비전은 각각 서로 다른 6종이며 실제 게임의 상점·보상·공유 풀·전투에서 사용합니다. 유닛 인스턴스만 복제한 것이 아니므로 2·4·6종 조합을 실제로 달성할 수 있습니다. 중복 종류·강화·대기석을 추가 인원으로 세지 않는 규칙은 유지합니다.

| 조합 | 기존 유닛 | 추가 유닛 |
|---|---|---|
| 수호 | 루멘, 아르덴 | 브릭 `bastion`, 로건 `vanguard`, 아이언 `sentinel`, 브루트 `breacher` |
| 정찰 | 실바, 카이 | 레이븐 `marksman`, 제트 `striker`, 에코 `tracker`, 쉐이드 `infiltrator` |
| 비전 | 노바, 세라 | 베가 `channeler`, 오닉스 `disruptor`, 루나 `medic`, 픽셀 `technomancer` |

## 빠르게 6→4→2종 확인하기

1. 서버를 재시작하고 새 **PvP 연습 · 봇 5명** 방을 만듭니다. 이 모드는 별도 DEBUG_GAME 설정 없이 디버깅 도구를 제공합니다.
2. **정보 → 디버깅 → 개발 디버깅 → 일시정지**를 누릅니다.
3. 시작 상태에서 **조합 · 수호 6종 / 전체 18종**, **정찰 6종 / 전체 18종**, **비전 6종 / 전체 18종** 중 하나를 골라 **시작 상태 적용**을 누릅니다.
4. 해당 계열 6종이 전장에, 나머지 12종이 대기석에 놓입니다. 레벨 6·100G·스테이지 3-2(라운드 7)이며 미니언 도입부를 건너뜁니다. 모든 참가자에게 같은 구성을 넣습니다.
5. 대기석은 꽉 차 있으므로 전장 유닛을 **대기석의 다른 계열 유닛 위로 드래그해 교환**합니다. 두 번 교환하면 원래 계열이 4종, 두 번 더 교환하면 2종입니다. 각 단계에서 기준 숫자와 대응 효과 수치가 흰색/회색으로 함께 바뀝니다. 다른 계열이 출전하면 그 계열도 조합 창에 나타납니다.
6. 조합 행은 `현재 인원 → 이름 → 2/4/6` 순서입니다. 툴팁을 열면 수호/정찰은 `+15%/30%/50%`, 비전은 `+30/60/100`을 확인합니다. 실제 적용되는 가장 높은 기준과 효과 값 하나만 흰색입니다. 4~5종이면 `4`와 `30%`만 흰색입니다.
7. **준비 완료** 후 매칭을 진행하거나 디버깅의 **다음 단계 / 1초 진행**으로 전투와 스킬을 봅니다. 저장·복원으로 같은 상황을 반복할 수 있습니다.

다른 플레이어를 관전 중이면 **내 전장으로** 돌아온 뒤 배치합니다. 원래의 **조합 · 기본 6종 (2/2/2)** 프리셋은 기존 유닛 6종으로 각 계열의 2종 효과를 비교할 때 사용합니다. 다른 시작 상태의 배치 규칙은 유지합니다.

## 임시 데이터와 수정 위치

- 기존 6종의 능력치·스킬·속성·이미지는 그대로입니다. 추가 12종의 능력치, 1~3 레어도, 공격/방어 4색 속성과 기존 스킬 조합은 균형을 맞추지 않은 임시 배정입니다. 실행할 때마다 값이 바뀌지 않도록 고정한 샘플입니다.
- 새 유닛도 액티브 1개+패시브 1개를 사용합니다. 기본 치명타 확률 10%, 총 치명타 피해 150%와 무기 위력 10을 유지합니다.
- 이미지 12개는 **500×500 투명 SVG**입니다. 기존 그림에 색상 회전과 `B3~B6`(수호), `S3~S6`(정찰), `A3~A6`(비전) 표시를 붙인 구분용 이미지입니다. 최종 캐릭터 그림이나 개별 무기/모션은 아닙니다.
- 이름·능력치·속성·스킬·이미지 경로: `shared/catalog.ts`의 `UNITS`. 종류 ID: `shared/model.ts`의 `Kind`. 새 이미지: `public/units/<kind>.svg`.
- `UNIT_KINDS`는 전체 18종, `CORE_UNIT_KINDS`는 기존 6종입니다. 정상 상점/보상은 전체 목록을 사용하며, 기존 혼합 디버깅 프리셋만 기존 6종을 사용합니다.
- 계열별 프리셋의 생성/배치: `server/debug.ts`, 메뉴: `client/main.ts`. 기존 공유 풀은 종류마다 30장이고 새 유닛도 같은 최대 강화 제외·판매 반환 규칙을 사용합니다.
