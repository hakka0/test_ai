# 0.10.0 경기·성장·합성·보상 규칙

TFT 일반 모드의 생존·경험치 구매·저축 경제를 참고했습니다. 현재 2인, 6종 예제 유닛, 자동 합성 구조에 맞춘 별도 밸런스이며 TFT를 그대로 재현한 모드는 아닙니다.

## 종료와 시간

- 체력 100 시작, 패배 시 체력 감소, 0 이하를 0으로 제한합니다.
- 결과 표시 6초 후 누군가 체력 0이면 경기 종료입니다. 양쪽 모두 0이면 무승부입니다.
- 최대 40라운드에서 체력 우선, 같은 체력이면 승수, 모두 같으면 무승부입니다. 3승 선취는 제거했습니다.
- 준비 30초(양쪽 준비 완료 시 단축), 전투 최대 40초, 결과 6초. 최대 계산 시간은 40×76초 = 50분 40초입니다. 서버 방 수명은 실제 시간 90분으로 늘렸습니다.
- 6라운드가 한 스테이지이며 1~6라운드를 2-1~2-6으로 표시합니다. PvE·공동 선택을 도입하지 않아 TFT 스테이지와 동일한 의미는 아닙니다.

| 스테이지 | 라운드 | 기본 피해 |
|---|---|---:|
| 2 | 1~6 | 1 |
| 3 | 7~12 | 2 |
| 4 | 13~18 | 3 |
| 5 | 19~24 | 4 |
| 6 | 25~30 | 6 |
| 7 | 31~36 | 8 |
| 8 | 37~40 | 12 |

패배 피해 = 기본 피해 + 승자 생존 유닛 수(최대 3). 무승부·양쪽 빈 전장·전투 시간 초과는 양쪽에 기본 피해를 줍니다. 승패를 조작하지 않고 경기 지연을 방지합니다. 피해 수치는 2인용 자체 설정입니다.

## 경제·경험치

시작 골드 10, 2라운드부터 준비 시작 때 기본 수입 5 + 전투 시작 잔액 기준 이자 + 직전 결과의 연속 수입을 지급합니다. 이자는 10골드당 1, 최대 5입니다. 연승/연패 2~3회는 1, 4회는 2, 5회 이상은 3입니다. 승리 골드 1은 결과 시점에 즉시 지급하며 다음 수입에서 중복 지급하지 않습니다. 무승부는 연속 기록을 초기화합니다. 화면의 최근 수입은 기본/이자/연속 내역이며 승리 보너스는 별도입니다.

다음 라운드 경험치 2, 경험치 구매 4골드로 4. 시작 1레벨·레벨당 출전 1명·최대 10레벨은 유지합니다.

| 현재→다음 레벨 | 필요 경험치 |
|---|---:|
| 1→2 | 2 |
| 2→3 | 2 |
| 3→4 | 6 |
| 4→5 | 10 |
| 5→6 | 20 |
| 6→7 | 36 |
| 7→8 | 56 |
| 8→9 | 68 |
| 9→10 | 68 |

1→10 누적 필요량은 268입니다. 초기 레벨에서 4XP를 구매하면 여러 레벨이 오를 수 있습니다. 최대 레벨의 경험치는 0으로 정리하며 추가 결제를 막습니다.

수동 리롤 가격은 5골드이며 구매·강화 1성 판매 가격은 레어도와 같습니다. 0.20.7부터 매 라운드 전투가 끝나 결과 단계로 넘어갈 때 양쪽 상점의 상품 5개를 무료로 한 번 갱신하고 구매 완료 칸도 채웁니다. 결과 단계에서 구매·수동 리롤할 수 있으며 다음 준비 단계에는 갱신하지 않습니다. 같은 종류가 다시 나올 수 있습니다. 레벨별 상품 확률·공유 유닛 풀·8인 매칭은 이번 범위에 포함하지 않았습니다.

## 배치 자리 교환 (0.9.2)

드래그 유닛을 다른 본인 유닛 위치에 드롭하면 서버가 두 위치를 한 번에 교환합니다. 전장과 대기석 사이 또는 같은 영역 안에서 가능합니다. 출전 수와 대기석 점유 수가 변하지 않으므로 정원/대기석 만석 교환을 허용합니다. 빈칸 추가 출전의 정원 검증과 준비 완료·마감·전투 중 배치 제한은 유지합니다. 강화·장비·골드는 변경하지 않으며 동일 위치의 반복 요청은 교환을 되돌리지 않습니다.

## 전투 중 상점 (0.9.1)

- 배치·대기석 이동·판매·경험치 구매·장비 변경·재료 조합·보상 선택은 준비 완료 전 준비 단계에서만 가능합니다.
- 전투 중 구매는 대기석에 추가하며 기존 자동 합성을 적용합니다. 합성은 보유 유닛에 즉시 반영되지만 현재 전투의 참가 유닛·강화 등급·능력치·장비·스킬·시너지는 시작 당시 상태를 유지합니다. 다음 전투에 강화가 반영됩니다.
- 대기석 만석 구매는 즉시 합성될 때만 허용합니다. 리롤 5골드와 중복/오래된 요청 검증, 상점 유지 규칙은 동일합니다.
- 다음 라운드 이자는 기존대로 전투 시작 잔액을 기준으로 고정하므로 전투 중 소비로 이미 정해진 이자가 줄어들지 않습니다.

## 유닛 합성

보유한 같은 종류·같은 강화 등급의 유닛 3개를 자동 합성합니다. 기본 구매·획득 유닛은 강화 1성입니다. 강화 1성 3개→2성, 강화 2성 3개→3성으로 연쇄 처리하며 3성끼리는 합성하지 않습니다. 레어도(캐릭터 종류별 가격 1~5성)와 강화 등급(개별 유닛 1~3성)은 별개입니다. 현재 레어도 4·5 유닛은 정의되지 않았습니다.

| 강화 등급 | 필요한 원본 1성 수 | 판매가 | 기본 체력·공격력 |
|---|---:|---|---|
| 1성 | 1 | 레어도 × 1 | 기본값 |
| 2성 | 3 | 레어도 × 3 | 기본값 × 1.8 |
| 3성 | 9 | 레어도 × 9 | 기본값 × 3.24 |

능력치는 최종 반올림 후 장비 고정 보너스를 가산합니다. 장비 보너스가 강화 배수로 늘어나지는 않습니다. 사거리·공격 간격·이동 간격과 스킬의 고정 피해/회복/보호막은 유지합니다. 공격력 비례 스킬 효과는 강화 공격력을 사용합니다.

- 전장과 대기석을 함께 검사하되 본인 유닛만 대상입니다. 보유 순서 중 전장 유닛을 먼저 남겨 ID·좌표를 유지합니다. 전장 유닛끼리 합쳐져도 빈 출전 자리를 자동으로 채우지 않습니다. 모든 강화 등급은 출전 한 자리입니다.
- 장비는 남는 유닛의 장비를 우선하여 최대 2개 유지하고 나머지는 인벤토리에 반환합니다. 두 단계 연쇄 합성도 같은 규칙을 적용하며 반환 내역을 합산합니다. 장비 복제·폐기는 하지 않습니다.
- 만석에서도 구매한 1성이 즉시 합성되면 허용합니다. 그렇지 않으면 결제·상품 상태·ID 발급을 바꾸지 않습니다. 판매해도 상품은 보충되지 않으며 유료 리롤만 상품을 보충합니다.
- 구매·리롤은 준비 완료 전 준비 단계와 마감 전 전투 단계에서 가능합니다. 준비 완료 후 대기·결과·경기 종료 단계에서는 거래를 막습니다. 서버 가격/버전 검증은 유지합니다. 클라이언트에서 가격·강화 등급·합성 결과를 지정할 수 없습니다.
- 상대에게 공개된 전장 유닛은 강화 등급을 표시합니다. 대기석의 강화 등급·합성 내역·소모된 ID는 본인에게만 전송합니다.

판매가 1/3/9배와 강화 배수 1.8은 이번 프로토타입의 초기 설정입니다. TFT의 합성 판매·시즌별 스킬 성장 규칙을 재현한 값은 아닙니다. `shared/merge.ts`, `shared/catalog.ts`, `shared/shop.ts`가 기준입니다.

## 경기 길이 확인

`npm run simulate`는 고정 난수 시드와 실제 서버 규칙을 사용해 화면·실제 대기 없이 세 가지 구매 전략으로 전체 경기를 계산합니다. 각 플레이어는 목표 레벨을 순차적으로 높이고 30/50골드 저축 기준을 사용하며 출전 유닛과 장비를 마련합니다. 준비 시간을 모두 쓰는 조건입니다.

| 저축 기준 A/B | 종료 라운드 | 가상 경기 분 | 종료 레벨 A/B |
|---|---:|---:|---|
| 30/30 | 22 | 16.66 | 8/8 |
| 50/50 | 22 | 16.68 | 8/8 |
| 30/50 | 22 | 16.53 | 8/8 |

0.8.0의 같은 시드 성장 도달 라운드는 6레벨 11, 7레벨 16, 8레벨 21입니다. 9·10레벨 도달 전에 끝났습니다. 0.6.0의 26~27라운드·19.1~20.0분, 0.5.0의 33라운드·25.7~25.9분은 해당 이전 버전 진단이며 현재 결과로 사용할 수 없습니다.

6종과 시너지로 구매·합성·전투 결과가 바뀌었습니다. 목표 25~35분을 달성하려면 후속 밸런스 조정이 필요하며, 사용자 요청에 따라 이번에는 수치를 재조정하지 않았습니다. 성장에 집중한 한 시드의 진단이고 일반 이용자 평균이나 모든 조합의 밸런스 검증은 아닙니다.

6종·3계열의 상세 규칙과 초기 효과는 SYNERGIES.md를 보세요. 서로 다른 같은 계열 2종, 대기석 제외, 중복 종류 한 번, 해당 계열 구성원만 강화, 전투 시작 조합 고정을 적용합니다. 합성·판매·출전 정원·공개 범위 규칙은 유지합니다.

## 라운드 보상과 제작

5라운드마다 준비 시작 시 3후보 중 1개 선택, 미선택은 골드 자동 수령합니다. 재료 2개를 소모해 완성 장비를 만드는 6개 제작법을 지원합니다. 상세한 초기 확률표와 제작 규칙은 REWARDS_CRAFTING.md를 참고하세요.

## 전투 결과 기록 (0.10.0)

전투 종료 시 실제 체력 전후/감소량·생존 수·승자·종료 사유를 기록하여 현재 경기 내내 유지합니다. 상세 조회는 BATTLE_HISTORY.md의 접힘 진행표를 사용합니다. 기록은 공개된 전투 결과 정보만 포함하며 경제/성장/피해 규칙을 변경하지 않습니다.
