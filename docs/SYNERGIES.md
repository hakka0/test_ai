# 유닛과 출전 조합 — 0.8.0

## 6종 유닛

| 계열 | 유닛 | 종류 ID | 역할 | 레어도 / 강화 1성 구매·판매 |
|---|---|---|---|---:|
| 수호 | 루멘 | knight | 피해 감소·방패를 사용하는 기사 | 1성 / 1 G |
| 수호 | 아르덴 | warden | 피격 충전 방패·체력 비례 회복 | 2성 / 2 G |
| 정찰 | 실바 | ranger | 원거리 관통 사격 | 2성 / 2 G |
| 정찰 | 카이 | skirmisher | 근접 쌍검·한시적 공격/이동 주기 단축 | 1성 / 1 G |
| 비전 | 노바 | mage | 범위 폭발·시작 보호막 | 3성 / 3 G |
| 비전 | 세라 | oracle | 최저 체력 비율 아군 치유·시작 보호막 | 2성 / 2 G |

시작 지급은 기존대로 루멘 전장 1명, 실바·노바 대기석입니다. 1레벨에는 출전 정원이 1명이므로 시너지가 켜지지 않습니다. 새 유닛은 상점에서 획득하고 계열 파트너를 출전시키세요. 상점은 6종을 균등 추첨하며 중복을 허용합니다. 레어도 1~5를 지원하되 이번 6종의 초기 레어도는 1~3입니다. 레벨별 확률·공유 유닛 풀은 아직 없습니다.

## 활성 조건과 효과

| 계열 | 필요한 서로 다른 출전 유닛 | 해당 계열 구성원에 적용하는 효과 |
|---|---|---|
| 수호 | 루멘 + 아르덴 | 강화 기본 최대 체력 ×1.15 |
| 정찰 | 실바 + 카이 | 강화 기본 공격력 ×1.15 |
| 비전 | 노바 + 세라 | 전투 시작 보호막 +30 |

- 같은 종류는 복사본 수·강화 등급이 달라도 한 종류입니다. 루멘 두 명으로는 수호를 켤 수 없습니다.
- 대기석은 제외합니다. 팀별로 실제 출전 정원에 들어간 유닛만 셉니다. 상대 유닛은 기여하지 않습니다.
- 효과는 그 계열의 모든 출전 구성원에게 적용합니다. 다른 계열은 강화하지 않습니다. 중복 출전 구성원도 활성 효과를 받습니다.
- 조합은 전투 시작 시 고정합니다. 파트너가 죽어도 그 전투의 효과는 유지하며, 다음 준비 단계 배치·회수·판매 결과로 다시 계산합니다.
- 강화 기본 체력·공격력은 기존 등급 배수 1.8^(강화−1)을 적용하고 반올림합니다. 그 결과에 시너지 배수를 적용해 다시 반올림한 뒤 장비의 고정값을 한 번 더합니다. 공격 주기·사거리·이동 주기는 시너지로 변경하지 않습니다.
- 비전 보호막은 장비·스킬의 시작 보호막과 합산합니다. 예: 노바는 비전30+별의 가호20=50, 부적 장착 시 85입니다. 전투마다 새로 지급하며 남은 이전 보호막을 누적하지 않습니다.
- 비율 치유는 전투 최대 체력을 사용하므로 수호 효과가 반영됩니다. 사망 아군은 치유하지 않으며 최대 체력을 넘지 않습니다.

이 효과와 신규 3종의 능력치·스킬 수치는 기능 확인용 초기 설정입니다. TFT 특정 시즌의 계열이나 밸런스를 복제한 수치가 아닙니다. 기존 3종 기본 능력치, 경제·XP·출전 정원·패배 피해·합성 배수와 판매 공식은 유지했습니다. 전체 밸런스 조정은 후속 작업입니다.

## 화면과 공개 범위

출전 조합 패널에서 계열 구성원, 0/2·1/2·2/2 종류 수, 활성 상태와 효과를 확인합니다. 준비에는 배치 미리보기, 전투·결과에는 시작 조합을 표시합니다. 파트너 사망으로 GUI의 활성 표시가 꺼지지 않습니다. 상점·대기석·유닛 상세에 계열이 표시됩니다. 출전 유닛의 상세 능력치는 시너지를 포함하며 대기 유닛에는 적용하지 않습니다. 비전 상세는 시너지 시작 보호막을 따로 안내합니다.

상대 공개 조합은 접속자별 공개 스냅샷의 출전 유닛과 Fighter로만 계산합니다. 상대 대기석·상점·경제·합성 내역을 보내거나 새 조합 필드로 추정 가능하게 만들지 않습니다.

## 빠른 확인

`npm run dev:debug`로 실행해 혼자 연습하기 → 개발 디버깅 → **조합 · 6종**을 선택합니다. 일시정지 후 시작 상태를 적용하면 양쪽 6레벨, 6종 강화 1성, 모든 시너지를 바로 확인할 수 있습니다. 준비에서 계열 파트너를 회수하고 다시 출전시켜 종류 수를 비교하세요. 전투를 시작하고 저장/단계 진행/복원으로 사망과 보호막 변화를 반복 확인할 수 있습니다.

규칙과 신규 스킬은 `tests/synergy.test.ts`, 실제 저장·복원·재접속 통신은 `tests/debug.network.test.ts`, 브라우저 조합 표시는 `tests/bench.browser.cjs`에 검사 항목을 넣었습니다. 브라우저·실기기 실행 여부는 VALIDATION.md를 확인하세요.
