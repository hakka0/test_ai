# 전투 시간과 피버타임 (0.20.55)

일반 전투는 **20초**, 그때까지 끝나지 않으면 **최대 15초의 피버타임**을 진행합니다. 피버도 끝나면 남은 전장은 시간 초과 규칙을 적용합니다. 먼저 승패가 난 전장은 즉시 멈추며 다른 전장의 피버 강화가 적용되지 않습니다. 미니언전도 같은 시간 구조를 사용합니다.

TFT의 [공식 13.22 패치에 설명된 점진 강화 방식](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/teamfight-tactics-patch-13-22-notes/)을 참고해 이 게임의 수치로 구현했습니다. TFT 전체 규칙이나 최신 패치의 완전한 복제는 아닙니다.

| 항목 | 이 게임에 적용한 수치 |
|---|---|
| 시작 | 전투 시작 20초 후 |
| 지속 | 최대 15초 |
| 강화 중첩 | 시작 시 1중첩, 이후 매초 증가, 최대 15 |
| 공격 속도와 기본/공격 스킬 피해 | 1.1의 중첩 수 제곱 배율 |
| 받는 회복과 새 보호막 | 중첩마다 10% 감소, 최대 70% 감소 |
| 이동 속도 | 피버 중 1.5배 |

공격 간격과 이동 간격은 기존 100ms 서버 진행 단위를 지킵니다. 이미 보유한 보호막을 소급해서 깎지는 않습니다. 방어력·치명타·배리어 분리 피해와 기여도 집계는 공통 피해 경로를 계속 사용합니다. UI의 기본 능력치 자체를 바꾸지 않고 실제 전투에 배율을 적용합니다.

피버 중 단계 제목과 타이머는 주황색이며 전장에 주황 윤곽을 표시합니다. 추가 점멸은 없습니다. 일시정지·배속·단계 진행·저장 복원·재접속 모두 같은 게임 시계를 사용합니다. 정보 → 디버깅 → 시작 상태의 **피버타임 · 방패 대결**로 장기 전투를 시험할 수 있습니다.

## 체력과 판매

플레이어 체력 피해는 **각 1:1 전투 종료 순간** 계산하고 순위표로 전송합니다. 6초 결과 페이즈가 끝날 때 다시 계산하지 않습니다. 6인 봇 방에서도 먼저 끝난 쌍의 피해는 다른 전장이 전투 중일 때 바로 전송합니다. 미니언전은 기존대로 플레이어 체력에 피해를 주지 않습니다.

판매는 준비 완료 전 준비 단계와 결과 단계에서 가능합니다. 전투 중에는 상세의 모든 판매 버튼, 상점 드롭, 직접 서버 요청을 차단합니다. 구매/리롤/장비 변경과 다음 준비 합성 규칙은 각 권한을 따릅니다.

## 직접 조절할 위치

- 시간: `shared/model.ts`의 `COMBAT_MS`, `OVERTIME_MS`.
- 중첩/배율: `shared/overtime.ts`.
- 전환/전장 정지/체력: `shared/engine.ts`.
- 공격 간격·이동·피해·회복·보호막: `shared/skills.ts`.
- 게임 시간 이동: `shared/game-time.ts`.
- 공개 상태: `shared/snapshot.ts`.
- 제목/타이머/판매 버튼: `client/main.ts`, 전장/툴팁 스타일: `client/style.css`.

검사: `tests/overtime.test.ts`, `npm run test:refinements55:browser`. [화면 측정](screenshots/refinements-0.20.55/results.json).
