# 플레이어별 공개 정보 (0.4.1)

`Match`와 `Player`는 서버가 판정에 사용하는 전체 상태입니다. 클라이언트 `Snapshot`은 별도 타입이며, `visibility`로 본인과 상대 데이터를 구분합니다. 본인에는 상점·골드·경험치·대기석·전체 장비를 보내고, 상대에는 이름·레벨·체력·연결·준비·승수·전장 유닛과 출전 장비만 보냅니다.

`GameRoom.publish()`는 방 상태를 broadcast하지 않고, 각 접속자의 `client.sessionId`로 `snapshotFor()`를 호출한 뒤 개별 전송합니다. 요청 본문에서 관전자 ID를 받지 않습니다. 재접속도 기존 접속 ID로 같은 전송 경로를 사용합니다. 봇의 데이터는 사람에게 상대 공개 범위로만 전달됩니다.

## 전송 규칙

- 본인 Unit에는 대기석 위치를 포함합니다. 상대 Unit에는 x ≥ 0인 전장 유닛만 포함하며 대기석 위치 필드는 없습니다.
- 상대 inventory에는 공개 유닛의 equipment에 연결되고 unitId도 일치하는 장비만 포함합니다. 대기석 장비와 미장착 장비는 제외합니다.
- 본인의 nextOfferId/nextUnitId 발급 카운터도 전송하지 않습니다.
- 전투에서는 양측에 같은 유닛 위치·체력·최대 체력·보호막·스킬 코스트·활성 상태·쿨다운·발동 횟수와 이벤트를 보냅니다. 공격/이동 예약 시각, 내부 버프 계산, 시뮬레이션 시각과 스킬 내부 갱신 시각은 보내지 않습니다.
- 모든 중첩 객체는 허용한 필드로 새로 생성합니다. 서버에 비공개 필드를 추가해도 자동으로 전송되지 않습니다. 스냅샷 수정은 서버 상태를 변경하지 않습니다.
- players 배열의 서버 순서를 유지하므로 두 번째 참가자의 좌표 반전은 기존 방식으로 동작합니다.

이미 공개된 전장 유닛을 회수하거나 장비를 해제하면 이후 스냅샷에서 숨겨집니다. 이전에 공개한 정보, 공개 행동으로 유추할 수 있는 정보까지 회수하지는 않습니다. 현재 관전 기능은 없습니다. 추가할 때에도 공개 스냅샷을 별도로 정의해야 합니다.

## 검증

`tests/snapshot.test.ts`: 양측 개인 정보 분리, 모든 경기 단계의 전송 범위, 회수·장비 해제, 향후 서버 필드 유출 방지, 서버 상태 불변, 알 수 없는 접속 ID 처리.

`tests/network.test.ts`: 실제 서버의 준비/전투/종료 전송, 상대 조작 거부, 경험치 구매의 개인/공개 상태 차이, 새 구매 유닛 비공개, 동일 전투 데이터, 재접속 후 본인 정보 복원과 상대 비공개 유지, 연습 상대 공개 범위.

## 0.5.0 추가 상태

플레이어 체력은 공개합니다. 경제 상태 streak/streakCount/lastIncome은 본인에게만 보내고 정산용 roundInterest는 누구에게도 보내지 않습니다. gameNow/timeScale은 같은 제한시간 계산에 필요한 공개 시간 정보입니다. 디버깅 상태는 서버가 허용한 개발 연습 방의 사람 접속자에게만 전송합니다. 전체 Match나 상대 경제를 디버깅 응답으로 보내지 않습니다.

## 0.6.0 합성 정보

전장 Unit과 Fighter에 강화 등급 rank를 공개합니다. 대기석 유닛의 rank는 본인만 확인합니다. 본인의 mergeRevision/lastMerge는 합성 알림에 사용하며 서버의 허용 목록으로 복사합니다. 상대 스냅샷에는 합성 내역·소모 ID·반환 장비 수를 포함하지 않습니다. 준비 중 합성으로 사라진 상대 전장 유닛은 이후 공개 목록에서 제거됩니다. tests/merge.test.ts와 실제 디버깅 서버 통신 검증이 이 범위를 확인합니다.

## 0.11.0 전투 기여도

완료된 전투 기록에는 그 전투에 실제 참가한 유닛의 ID/소유자/종류/당시 강화와 준 피해/받은 피해/유효 회복/보호막 흡수량을 양측에 동일하게 보냅니다. 대기석, 상점, 합성 소비 목록, 장비 목록과 전투 중 내부 누적 객체는 기여도 전송에 포함하지 않습니다. 이미 공개된 참가자가 전투 중 합성으로 보유 목록에서 사라져도 해당 전투 기록에는 남습니다. 명시적 허용 목록과 값 복사로 미래 비공개 필드나 결과 조회에 의한 서버 변경을 막습니다.

## 0.12.0 최종 결과

종료 사유 endReason과 방의 연습/대전 mode는 공개 메타데이터입니다. 최종 결과는 이미 공개된 이름/체력/승수와 경기 winner, 완료 기록 수만 사용합니다. 새로운 상대 경제·대기석·장비 내역은 공개하지 않습니다. 새 방/로비 이동 시 클라이언트의 이전 경기와 재접속 토큰을 초기화하며 이전 방의 늦은 메시지가 새 세션의 상태/토큰을 덮어쓰지 않도록 연결 세대를 검사합니다.
